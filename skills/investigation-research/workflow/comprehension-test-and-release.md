# 独立理解测试与交付

## Input

- 原始研究请求、研究对象契约与完成标准。
- 最终报告。
- 主控提供的一段完整测试片段：只用于结构归类，不指向当前用户或需要作现实决定的新对象。
- 测试片段的可寻址来源与选择理由。
- 独立理解测试契约。

## Goal

取得独立读者能够重建、归类和追溯信息体系的行为证据，并确认报告没有越权替用户或后续流程作现实裁决。

## Guidance

测试片段必须未被报告原样归类，并至少触及认识状态、不可比性、相反材料或范围边界中的一项承重边界；主控记录选择理由，但不把理由或预期归类交给测试者。随后把测试输入交给一个未参与研究、归纳和写作的 Subagent，不给搜索过程或主控解释。测试者必须：

- 用自己的话重建对象骨架和六层信息体系。
- 将给定测试片段放入正确层，指出它会要求检查哪条既有边界以及还缺哪些材料；不得判断片段主张真假、不得把既有模式套用到片段对象。
- 解释至少一组表面冲突：共同对象、差异轴、材料可见的分组与未解部分。
- 从一项规律性特征追到前提/条件、材料、相反内容和重查边界；报告同时含结构性关系和条件性模式时，两类各抽查至少一项。
- 构造两个事实输入相同、价值权重明显不同的假想读者；不替二者作选择，只检查报告是否预设一方目标、遗漏另一方需要的事实维度，或用篇幅/顺序/措辞迫使二者收敛。
- 标出任何开放现实主张真假判决、客观有效/个体适用裁决、方案评价/筛选/排序/推荐或隐性价值倾向。

失败按责任节点精确回开：对象或范围错误回 N1；缺关系/情境回 N2；不可追溯或材料还原定位错误回 N3；六层错分、模式越界或争议被抹平回 N4；叙事难懂或暗含推荐回 N5。测试者只检查报告内部是否支持这些归纳，不裁定研究对象在现实中是否正确。修复后重新执行完整测试。

通过条件：独立读者能重建全貌、归类给定片段、解释争议并完成追溯；关键未知被看见；不同价值取向不会被报告强制收敛到同一选择。

## Execution Mode

必须委派独立 Subagent。环境确实没有独立执行者时，不得自测冒充独立行为证据，只能以“部分成功—待独立理解测试”封口，并保留报告、测试契约和恢复入口。

## Static Check

- 测试的是读者行为，不是“报告看起来完整”。
- 测试片段完整、可寻址、未被报告原样归类、触及至少一项承重边界且非个体适用场景；测试者没有自行构造现实事实或执行新搜索。
- 每个失败项都路由到唯一最早责任节点，未以“再多搜一点”笼统处理。

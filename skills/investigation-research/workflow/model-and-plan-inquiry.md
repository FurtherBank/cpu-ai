# 建立探索模型与调查任务

## Input

- 当前确认的研究对象契约及版本。
- 用户提供的材料、已知事实与已知未知。

## Goal

形成暂定探索模型和调查任务账。探索模型描述对象与哪些概念、组成、机制、情境、差异和失效关系相连；调查任务账把关键缺口变成可搜索、可封口的任务。

每个任务必须绑定六层信息体系中的至少一层，并记录：任务 ID、待理解关系、预期材料类型、时间/地域/版本、完成信号、发现新关系后的回写位置。

## Guidance

沿以下关系外展，而不是只扩充同义关键词：

- 指称：别名、旧名、专业名、社区用语和近敌。
- 构成：组成部分、职责边界、输入输出和生命周期。
- 机制：材料提出的作用路径、中间状态与替代解释。
- 情境：人群、阶段、环境、实施方式、版本与制度条件。
- 差异：结果为何不同、材料为何不一致、哪些变量可能解释分化。
- 失效：失败方式、反例、限制、异常与未知依赖。
- 职责性权威与时间：谁因职责可对什么范围作正式说明，规则和实现在哪个版本有效；身份本身不证明经验性主张为真。

关系准入条件：能补足对象骨架、解释一项范围内基线、区分关键分化情境、定位争议、支持或限制一项规律性特征，或界定未知。不能以“有助于选择哪个方案”作为准入理由。

因果内容一律标成“某材料作者的因果主张”或“研究者待查的竞争解释”，不把先后、相关或共同出现升级成本 Skill 确认的因果。模型是搜索导航图，不是先验结论；新材料改变概念或关系时必须换版。

## Execution Mode

主控执行。可让 Subagent 对一个边界明确的关系单元提出查询线索，但主控负责合并模型和任务依赖。

## Static Check

- 每个调查任务都能指出要改变六层体系中的哪一处。
- 任务包含差异、反例与边界材料，不只寻找支持性内容。
- 模型没有候选方案池、效用指标、排序或推荐字段。

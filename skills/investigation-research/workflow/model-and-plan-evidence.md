# 建立现实模型与取证任务执行指导

## Input

- 必须入参：已放行的现实问题—判断单元及其版本。
- 已有事实、来源和未知。
- 按需参考：[证据与模型](../references/evidence-and-model.md)。

## Goal

从“知道要支持什么判断”转成“知道现实中哪些关系待证、应取得什么证据”。完成时交付：

- 暂定现实模型：概念、实体、关系、竞争解释、适用条件、权限、时效和未知。
- 取证任务账：每项任务包含待证明/区分/反驳内容、候选材料类型、结果可能取值、会改变的下游判断和停止信号。
- 模型版本；所有条目保留认识状态和来源。

本阶段不把搜索结果当证据，不生成完整候选行动空间。

## Guidance

不要从同义词表开始。先问哪些现实关系一旦取值不同，会让解释、适用性、候选、风险或停止条件走向不同路线。

- 概念问题：区分近敌及其可观测差异。
- 因果问题：至少保留两个能产生不同预测的竞争解释；指标错误和样本变化也可成为竞争解释。
- 设计/选择问题：建立目标—职责—机制—失效—代价关系。
- 规则问题：建立权源—地域—日期—适用主体—义务—例外关系。
- 个体化问题：建立个体条件—证据适用性—风险—决定权关系。

无法说明会改变哪个判断的关系先排除；记录排除理由，避免后续反复发现。

## Execution Mode

- 主控执行，保持 N1 目标和持续模型版本。
- 发现研究契约核心字段改变时回 N1 换版；只需补模型概念或关系时留在本阶段。
- 产出写入 [研究工作簿模板](../templates/research-workbook.md) 的“暂定现实模型”和“取证任务账”。

## 静态校验

- 每项取证任务是否绑定一个承重缺口和一个下游影响？
- 竞争解释是否在未被证据区分前仍然存在？
- 是否把未知写成未知，而不是用常识补成事实？
- 是否出现了与判断无关的百科分支？有则清退。

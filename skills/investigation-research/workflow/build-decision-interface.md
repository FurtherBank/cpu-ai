# 形成下一步判断接口执行指导

## Input

- 必须入参：候选空间、N1 目标判断与权限、模型和证据追溯链。
- 只有用户明确提供的价值偏好、资源、风险容忍和时间约束可用于排序。
- 按需参考：[候选与判断](../references/candidate-and-decision.md)。

## Goal

形成可独立阅读的下一步判断接口。报告至少包含：

- 研究对象、当前结论范围和一句话判断。
- 本接口消费的契约、模型、证据账和候选空间版本。
- 对现实的当前理解，包括关键关系和竞争解释。
- 候选比较：解决/不解决、依据/反证、适用条件、代价、风险、权限。
- 选择会被什么信息、价值或外部变化翻转。
- 当前不可判断项、最值得补取的信息及依赖顺序。
- 时效、失效重开条件和来源索引。

## Guidance

围绕下游决策组织，不按搜索顺序或来源类型堆材料。事实写证据；推断写推导链和不确定性；价值取舍注明来自用户还是仍待确认；专业决定只标出接口和需核实问题。

当证据不足以选唯一方向时，用条件分支表达：如果条件 A 成立，候选 X 更合适；若 B 未知，先取得信息 Y。不要用“综合来看建议……”掩盖未经授权的权衡。

## Execution Mode

- 主控执行，连续消费目标、模型、证据和候选。
- 报告使用 [研究工作簿模板](../templates/research-workbook.md) 的“最终判断接口”。
- 写完先执行 SKILL.md 的静态校验；失败按责任回开，再进入独立消费测试。

## 静态校验

- 一个未参与研究的人能否定位每条承重结论的来源、条件和强度？
- 是否完整呈现候选，而不是只呈现作者偏好的方向？
- 是否能说出什么尚不能判断、补什么最有价值？
- 是否把研究结论与真实实施/治疗/注册/购买后的验收证据分开？

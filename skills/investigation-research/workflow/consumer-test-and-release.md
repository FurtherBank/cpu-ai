# 独立试用并放行执行指导

## Input

- 用户原始问题原文。
- N1 的目标判断和完成标准。
- 最终判断接口，不提供搜索过程、作者解释或预期答案。
- 按需参考：[完成与回开](../references/quality-and-reopen.md)。

## Goal

用独立消费行为验证报告是否真正减少下游补工。测试必须产生：测试者执行的任务、预期结果、实际结果、逐项证据、失败位置、回开节点和最终状态。

## Guidance

消费任务应复现真实用途，而不是让测试者审稿。例如：

- 产品决策者据报告说出当前候选、依据和下一项实验。
- 用户据报告整理要向医生或专业人员提供的事实与问题。
- 购买决策者据报告选出满足给定条件的方案并说出翻转条件。

要求测试者不访问研究过程。若报告本身明确指向一个待补原始来源，测试者可检查该链接是否可寻址，但不得自行重做整个调查来帮报告过关。

## Execution Mode

- 必须委派未参与本次综合的独立 Subagent。使用 [消费测试 Prompt](../templates/consumer-test-prompt.md)，原样填入输入。
- 测试者返回失败项与风险优先的报告；每项必须有实际操作和证据。纯文字评价不算测试。
- 主控按以下路由回开：
  - 对象、目标、风险或权限改变：N1。
  - 新概念、关系、竞争模型、适用性或新证据需求：N2。
  - 已有取证任务的来源失效或强度不足：N3。
  - 缺候选、排除理由或覆盖：N4X。
  - 候选已有但比较条件或表达不可消费：N4。
- 修复后必须重新执行独立测试。没有可用 Subagent 时，以 `部分成功—待独立测试` 封口，记录报告路径、测试输入包和恢复入口；不得放行。

## 放行判据

- 下游无需重建概念空间、核验全部证据、生成候选或辨认决定权。
- 下游能说出当前可选下一步、各自依据与条件、不可判断项、补取信息和失效条件。
- 信息不足时，只需执行一组已定位、有依赖顺序的补取任务。
- 行为日志已通过结构和影响闭包校验。

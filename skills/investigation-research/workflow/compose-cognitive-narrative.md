# 编排主线认知叙事

## Input

- 六层信息体系、规律性特征账和材料追溯链。
- 研究对象契约中的目标读者与理解粒度。

## Goal

形成一条最简单清晰、又不损失承重边界的主线认知叙事，使读者第一次阅读便能理解全貌，不必按搜索顺序自己拼接材料。

默认主线为：对象骨架 → 范围内基线 → 关键分化情境 → 差异与争议位于哪里 → 能归纳出的规律性特征 → 特征边界与未知。

## Guidance

- 按读者理解对象的依赖顺序组织，不按来源、渠道或搜索轮次组织。
- 每一节只承担一个认知转换；支线只在解释承重节点时展开。
- 高层陈述建立“叙事段落 → 信息层/特征 ID → 材料卡 → 原始来源”追溯链。
- 来源和方法细节就近简述，完整信息收拢到材料索引，避免打断主线。
- 对同一概念只用一个名字；首次出现的自造术语给定义和白话例子。
- 争议先说明共同对象和差异轴，再列条件分支与未解部分，避免写成观点名单。
- 不用顺序、篇幅、形容词、默认场景或“综合来看”暗示某个现实方案更优。
- 结尾只总结“现在可以如何理解、材料共同呈现了哪些规律性特征、边界在哪里、哪里仍未知”，不写行动建议、优先级或推荐。

## Execution Mode

主控执行。可以委派文字冷读，但叙事结构与信息体系的一致性由主控负责。

## Static Check

- 裸读者能画出对象骨架并说清关键关系。
- 删除来源索引后主线仍可理解；追回来源时每项承重陈述仍可寻址。
- 报告没有把材料中的建议改写成本 Skill 的建议，也没有隐性方案排序。

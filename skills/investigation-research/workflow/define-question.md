# 定界现实问题执行指导

## Input

- 必须入参：用户原话、启动调研的现实处境、期待调研支持的下一步。
- 可选入参：已有材料、时间窗、资源限制、不可接受后果、已知权限。
- 按需参考：[研究对象与分流](../references/research-object.md)、[风险与权限门](../references/risk-and-authority.md)。

## Goal

把“主题或结论式问句”转成版本化的现实问题—判断单元。完成时必须包含：

- 用户原话的可寻址引用，不用重构后的表达覆盖原话。
- 当前现象或目标、相关主体、具体情境、时间尺度。
- 调研后要支持的下一步判断。
- 重要结果与不可接受后果。
- 决定权边界、风险等级和本轮排除项。
- 输入陈述、事实、推断、假设、决定和未知的初始区分。
- 完成标准：下游最终要能做什么；信息不足时允许交付什么。
- 风险等级、最低证据门槛和专业升级条件。

本阶段不搜索，不诊断，不生成方案。

## Guidance

先找“用户调研完准备做什么”，再追问会翻转这项判断的信息。只有承重未知才值得追问；能在后续安全保留为条件分支的未知，不应阻断启动。

出现以下信号时改走：

- 危险信号、法定/业务截止时间或研究会延误必要处置：停止研究，交给有权限者。
- 用户只需稳定、单一事实：转简单查询。
- 用户已有明确方案并要求实施：转执行或验证流程。
- 一个问句包含不同证据体系或决定者：拆成相互引用的判断单元。

## Execution Mode

- 主控执行，原因是本阶段强依赖用户语境、目标和决定权。
- 用户缺少非承重信息时，用显式未知继续；缺少会改变安全或研究对象的承重信息时，先澄清或分流。
- 产出使用 [研究工作簿模板](../templates/research-workbook.md) 的“现实问题—判断单元”。

## 静态校验

- 能否用一句话回答“谁在什么处境下，需要弄清什么，用来作出什么判断”？
- 是否写清错判后果和谁有权决定？
- 是否保留原话与认识状态？
- 是否完成分流检查？

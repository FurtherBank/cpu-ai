# 生成候选空间执行指导

## Input

- 必须入参：当前暂定现实模型、明确记录已消费该契约与模型版本的证据账、权限边界。
- 按需参考：[候选与判断](../references/candidate-and-decision.md)。

## Goal

生成候选判断与行动空间。先记录本次消费的契约、模型和证据账版本；每项候选包含来源关系、企图改变的结果、作用路径、适用条件、不适用条件、证据状态、主要风险、决定权状态和排除/保留理由。另列候选覆盖未知。

本阶段不排序，不替用户确定价值，不生成专业处置细节。

## Guidance

分别用以下透镜扫描模型，不要求每种都产生候选：

- 机制：能否改变承重机制或中间状态？
- 原因：能否验证、缓解或排除高价值竞争解释？
- 职责：谁或什么机制应承担缺失职责？
- 失效：能否预防、检测、恢复或退出？
- 信息价值：哪个低代价动作最能区分分支？
- 权限：哪些方向只能形成记录、沟通、核实或交给专业人员的问题？

候选必须追回证据约束的现实关系。未知可限制候选，但不能充当候选依据。没有候选是合法状态，说明缺口并回开。

## Execution Mode

- 主控执行，因为候选生成依赖完整模型、目标和权限。
- 新概念、关系或证据需求回 N2；已有取证任务来源失效或强度不足回 N3。
- 用 [研究工作簿模板](../templates/research-workbook.md) 的“候选空间”记录。

## 静态校验

- 每项候选能否追回至少一条现实关系和相称证据？
- 近邻方向为何未进入，是否有可检查的排除理由？
- 是否记录可能遗漏的结果、机制或行动方向？
- 专业候选是否保留但未被 Skill 排序？

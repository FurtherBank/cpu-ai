# 归纳信息体系与规律性特征

## Input

- 当前探索模型、调查任务账和材料账，以及三者版本依赖。
- 研究对象契约中的范围、受众和理解粒度。

## Goal

把分散材料归纳为六层信息体系：

- 对象骨架：对象是什么，由什么构成，各部分如何关联。
- 范围内基线：分为可直接核对的闭合事实，以及可比材料在明示范围内的跨材料一致呈现；两者不得混写。
- 关键分化情境：材料在这些情境下呈现不同表现、解释口径或模式边界；不把情境写成本 Skill 确认的因果变量。
- 差异、争议与边界：材料分歧落在哪条轴上，哪些可按情境分组，哪些仍冲突。
- 规律性特征：包括由定义、代码、条款或公式推出的结构性关系，以及跨材料反复呈现的条件性模式。
- 未知：当前材料不能回答、不可比较或需要新类型材料才能推进的部分。

“闭合事实”只指能在明确边界内直接核对的身份、版本、原文、代码位置、制度文本或数学定义等命题；不含疗效、机制、社会效果、经验好坏等开放现实主张。

## Guidance

结构性关系记录：类型、明示前提、推导链、来源版本、适用范围和不可推出内容。静态代码可以说明该版本存在什么路径，不能说明运行时实际走过该路径或它造成了某结果。

条件性模式记录：

> 在所查材料范围 S 与材料所述条件 C 内，A 与 B 反复呈现关系 R；呈现该关系的材料 E；材料作者的机制/因果主张状态 M；相反或例外材料 X；出现 F 时需要重查。

- 条件性模式至少来自两项可比较材料；单项研究、单个故事或一次运行只能保留为材料观察、作者主张或模式线索。
- R 只写共同出现、相关、先后或分化。材料作者提出因果时，将其放入 M，并附设计基础；本 Skill 不确认现实因果成立。
- 先按差异轴拆解争议，再归类为口径差异、情境分组、材料限制、未解冲突或不可比较。
- 关键分化情境的准入标准是它能解释材料呈现为何不同，而不是与用户故事表面相似。
- 高层归纳必须保留材料身份、材料直接覆盖范围和相反/例外材料的追溯链。
- 结构性关系与条件性模式都只压缩理解，不推出“用户应当做什么”，不得生成、筛选或排序实际方案。
- 六层都必须检查；没有足够内容时明确留空并说明需要何种材料，不用常识制造基线或模式。

## Execution Mode

主控执行。跨材料归类、争议建模和规律性特征命名不得拆给互不共享全局模型的并行任务。

## Static Check

- 来源身份事实、闭合事实、材料主张/观察、跨材料一致呈现、结构性关系、条件性模式、研究者推断、争议和未知没有互相冒充。
- 每条高层内容都能回溯到材料卡、认识状态和材料直接覆盖范围。
- 两个价值取向不同的读者可以共享这套信息体系，同时保留不同的后续选择空间。

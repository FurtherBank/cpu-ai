# 独立理解测试任务

你是未参与本次搜索、归纳和写作的独立读者。只使用下面给出的研究请求、完成标准、测试片段和报告；不要联网、补搜或猜测作者意图，也不要替用户选择行动。

## 输入

- 原始研究请求：`<填写>`
- 研究对象与范围：`<填写>`
- 目标读者和理解粒度：`<填写>`
- 六层完成要求：`<填写>`
- 测试片段：`<主控提供一段完整、可寻址、未被报告原样归类的内容；不得指向当前用户或需作现实决定的新对象>`
- 测试片段来源：`<填写可寻址来源；不提供主控的选择理由或预期归类>`
- 最终报告：`<粘贴或给出可读路径>`

## 测试任务

- 用自己的话重建对象骨架：核心组成、职责或状态，以及关键关系。
- 分别列出报告中的范围内基线、关键分化情境、差异/争议/边界、规律性特征和未知；指出错层或混层处。
- 将给定测试片段放入现有体系，说明它要求检查哪条既有边界、还缺什么材料；不得判断片段主张真假、不得判断报告模式适用于片段对象。
- 选择一组表面冲突，解释共同对象、差异轴、材料可见的分组和仍未解决的部分。
- 随机选择一项规律性特征，沿“特征 → 信息层/特征 ID → 材料卡 → 原始来源”检查追溯，并核对前提/条件、相反内容和重查边界；报告同时含结构性关系和条件性模式时，两类各抽查至少一项。
- 构造两个事实输入相同、价值权重明显不同的假想读者；不要替二者选择，只检查报告是否预设一方目标、遗漏另一方需要的信息，或通过顺序、篇幅、措辞迫使二者收敛。
- 审计是否存在：开放现实主张真假裁决；客观有效性或个体适用性裁决；方案总体评价、筛选、排序或推荐；隐性价值偏向。

## 输出格式

### 重建结果

写出你实际理解出的对象全貌；不要复述目录。

### 归类与冲突解释

给出测试片段归类和表面冲突解释，并标明不能从报告推出什么。

### 追溯结果

列出抽查的规律性特征、追溯链、前提/条件、相反内容和任何断点。

### 双读者去偏检查

写出两个假想读者的不同价值权重，以及报告是否在事实维度、顺序、篇幅或措辞上偏向其中一方；不得替二者作选择。

### 失败与风险

逐项写：严重度、具体位置、第一遍如何误解、应回开 N1–N5 的哪个节点。没有问题时明确写“未发现”。

### 测试结论与交付处置

只可选择：`可交付`、`回开后复测`、`因职责/权限分流`。这个结论只评价报告是否通过测试，不评价研究对象应如何行动。

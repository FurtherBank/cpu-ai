# 探索模型与材料还原定位

## 本文件解决什么

本文件统一 N2 的探索模型、N3 的材料账和跨材料关系。它保证研究者可以还原材料原意并放入信息体系，却不会把材料内容偷换成现实裁决。

## 认识状态

| 状态 | 可写内容 | 不可升级为 |
| --- | --- | --- |
| 输入陈述 | 用户或任务给出的说法 | 已证实事实 |
| 来源身份事实 | 作者、机构、版本、日期、原文位置 | 来源所述内容为真 |
| 闭合事实 | 明确版本、文本、代码、定义或来源身份内可直接核对的命题 | 其它版本、运行时或现实效果 |
| 材料主张或观察 | 材料实际说了什么、观察到什么 | 开放现实主张真假 |
| 跨材料一致呈现 | 可比较材料在相应范围内呈现相似方向 | 领域现实事实 |
| 结构性关系 | 明示前提下可从定义、代码、条款或公式推出的关系 | 经验频率、效果或运行时因果 |
| 条件性模式 | 所查材料在明示条件下反复呈现的关系 | 现实因果定律或行动建议 |
| 推断 | 从材料和明确前提推出的解释 | 材料直接结论 |
| 争议 | 材料在同一比较轴上不一致 | 某方必然错误 |
| 未知 | 现有材料不能回答或不可比较 | 不存在、无效或不重要 |

“材料直接覆盖范围”指材料的方法、样本、时间和情境直接容许研究者转述到哪里。说白了，它是还原材料原意时不能越过的边界，不是材料主张为真、做法有效或适合用户的证明权限。

## 探索模型

探索模型的最小节点是对象、概念、组成部分、状态、情境、结果、异常、材料和职责性权威；最小边是：

- 指称或近敌关系。
- 组成、职责、输入输出和生命周期关系。
- 机制/因果主张与竞争解释。
- 情境或变量对表现的分化关系。
- 观察、测量和主张之间的支撑关系。
- 失败、反例、例外和失效关系。
- 版本、地域、时间与职责性权威关系。

每条边标注状态：材料直接陈述、材料内推断、研究者跨材料推断、冲突或未知。模型换版时记录触发材料及受影响调查任务。

## 调查任务契约

每项任务包含：

- 任务 ID、自身版本与实际消费的研究对象契约/探索模型版本。
- 待理解的节点或关系，不用宽泛主题代替。
- 它补足六层信息体系中的哪一层。
- 预期材料类型、查询入口、时间/地域/版本。
- 完成信号和局部停止条件。
- 新概念、反例或冲突出现时的回写位置。

不得出现“是否改变选择、证明哪个方案、排除哪个候选”一类任务目的。

## 材料卡契约

材料卡必须能让未参与搜索的人恢复以下内容：

- 材料身份与原始位置。
- 材料卡自身版本，以及所消费的研究对象契约、探索模型和调查任务账版本。
- 原文实际主张或观察。
- 方法、样本、测试、实施过程或经验观察基础。
- 直接覆盖范围与未覆盖范围。
- 限制、异常、相反材料和时效。
- 与其它材料的可比轴及关系。
- 当前认识状态、服务任务和信息层。

二手材料不能继承原始材料未被二手内容准确保留的细节。原始源不可得时，记录追溯尝试和缺失，不用多个转述制造虚假独立性。

## 材料关系处理

先确认材料讨论的是不是同一对象、口径、结果和时间，再比较：

- 方向一致：在可比范围内独立呈现相似内容；只描述材料关系，不宣布共同主张为真。
- 补充：分别覆盖同一关系的不同部分。
- 情境分组：材料在已识别情境下呈现不同内容；不由本 Skill 确认该情境造成差异。
- 表面冲突：用词或指标不同，转换后未必相反。
- 实质冲突：在可比范围内仍给出不一致内容。
- 尚不可比较：缺少关键口径、方法或上下文。

冲突不得通过来源数量投票解决。保留差异轴、各自材料直接覆盖范围和要推进理解仍缺什么。

## 版本依赖

最小依赖链为：

```text
研究对象契约 → 探索模型 → 调查任务账 → 材料账 → 六层信息体系 → 规律性特征账 → 主线认知叙事
```

每个正式制品同时记录自身版本与所消费的直接上游版本。研究对象范围、模型关系、任务口径、材料集合、六层归类或规律性特征发生材料性变化时提升相应版本。上游变化后，只重开真正受影响的下游内容；未做影响分析前不得假定旧归纳仍适用。

## 工程材料能说明到哪里

- 文档：说明该版本公开承诺或描述了什么。
- 静态代码：说明该版本存在何种实现路径，不说明运行时走过该路径。
- issue 或用户报告：说明有人报告过现象，不说明根因或发生率。
- 单次日志：说明该次运行的可观察序列，不自动说明普遍机制。
- 受控复现或测试：在其环境、输入和版本内说明可重复行为，不自动外推其它部署。

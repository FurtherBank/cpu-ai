# 现实模型、取证任务与证据裁定

## 调用契约

- 使用时机：N2 建模和定义取证任务；N3 裁定材料并同步模型。
- 输入：现实问题—判断单元、已有事实/来源、候选材料。
- 输出：认识状态明确的现实模型、取证任务和证据主张。
- 不负责：按用户价值排序候选或作最终决定。

## 认识状态

| 状态 | 含义 | 写法要求 |
| --- | --- | --- |
| 输入陈述 | 用户或任务输入确实这样说 | 不自动证明陈述内容为现实事实 |
| 事实 | 当前证据足以在明示范围内依赖 | 附来源、范围和时效 |
| 推断 | 由事实和前提推出 | 写清推导链及可反驳条件 |
| 假设 | 为继续调查暂时采用 | 不进入事实性结论 |
| 决定 | 有权限者作出的选择 | 标明决定者和适用范围 |
| 未知 | 当前不能判断 | 写清它会改变什么，以及如何补取 |

## 建模关系

按问题选择关系，不要求机械填满：

- 指称与近敌：同一词是否指不同对象，不同词是否指同一现象。
- 机制与因果：输入怎样改变中间状态与结果；有哪些竞争解释。
- 职责与实现：需要承担什么职责，哪些机制或角色可能承担。
- 适用与异质性：对谁、在何条件下成立，哪些条件会翻转。
- 失效与恢复：怎样失败、如何检测、缓解、恢复或退出。
- 规则与权源：谁制定、适用于何地/何人/何时，有何例外。
- 价值与权限：哪些是事实判断，哪些需要用户偏好或专业决定。

## 取证任务格式

每项取证任务回答：

- 要证明、区分或反驳什么？
- 当前有哪些竞争取值或解释？
- 哪种材料类型具有相称证明权限？
- 结果不同会改变哪个模型关系、候选、风险或停止条件？
- 什么结果足以停止这一查询路径？

“搜索 POTS 康复建议”不是取证任务；“区分某类活动后恶化是否会改变运动建议的适用边界，需要指南/研究与相似患者的执行性材料分别承担什么证据职责”才是。

## 证明权限

证明权限是一份材料在来源、方法、样本、情境与时间边界内最多能支持的主张强度。

| 材料 | 通常可以支持 | 单独不能支持 |
| --- | --- | --- |
| 原始研究/系统综述/指南 | 研究定义、群体结果、风险与证据等级 | 未覆盖个体的确定适用结论 |
| 官方法规/政务/产品文档 | 当前明示规则、条件、能力或承诺 | 未公开内部机制、真实效果或个案适用裁定 |
| 开源代码/技术实现 | 该版本代码中的实现与行为 | 其它产品、部署或运行中的真实配置 |
| 专业人员公开分享 | 专业实践框架、操作建议与待核实问题 | 对具体用户的正式诊断、法律或税务意见 |
| 患者/用户/经营者经历 | 经历存在、体验、执行障碍、失败和新检索线索 | 普遍疗效、安全、因果或权威规则 |
| 营销材料 | 产品如何表述自身能力 | 独立效果、比较优势或内部架构 |
| 内部数据 | 当前系统/样本中的观测关系 | 未经设计与排除的普遍因果 |

## 冲突裁定顺序

不要按来源数量投票。依次检查：

- 是否讨论同一个概念、结果和时间窗。
- 原始源与转述是否一致。
- 方法、样本、比较组和测量是否不同。
- 适用主体、地域、版本或时间是否不同。
- 是否存在利益关系、选择偏差或幸存者偏差。
- 冲突能否由更精确的条件分支保存，而非强行消除。

无法消解时保留冲突及其对选择的影响。

## 模型—证据同步门

任何证据若改变模型中既有关系的确认/否定状态、强度、适用范围，或带来新概念、竞争解释与未知，都必须回写模型并升级版本。N4X 只能消费当前模型，以及明确记录已消费该契约和模型版本的证据账；不得接收未解释冲突。

## 版本身份

- 契约换版后，旧模型、任务和证据不得自动继承；逐条标记继承、待重新裁定或失效。
- 模型每次因新证据改变认识状态或关系时升级版本。
- 取证任务账记录其生成时的契约和模型版本；任务集合变化时升级任务账版本。
- 每项证据记录 Subagent 实际消费的契约、模型和任务账版本。
- 证据账有独立版本：新增、删除、重新裁定证据主张，或改变主张强度、适用范围、冲突和失效条件时升级；纯格式修正不升级，但写更正记录。
- 并行结果回收时若版本落后，不得直接合并；先检查任务前提在当前模型中是否仍成立，再重新裁定或重发。
- 候选空间有独立版本：候选纳入/排除、来源关系、适用性、权限或覆盖未知改变时升级。模型或证据账升级后，旧候选空间自动标记为待重新生成，除非逐条确认继承并记录依据。
- 判断接口有独立版本，并记录其消费的全部上游版本。上游任一版本升级后，旧判断接口自动失效，必须重新生成或逐条重验后才能进入 N5。

# 信息体系归纳与认知叙事

## 六层信息体系

| 层 | 回答的问题 | 最低归纳条件 |
| --- | --- | --- |
| 对象骨架 | 对象是什么、由什么构成、关系如何 | 概念与关系可追溯，近敌已区分 |
| 范围内基线 | 所查范围中哪些内容可直接核对，哪些观察被材料共同呈现 | 闭合事实与跨材料一致呈现分开，材料集合和范围明确 |
| 关键分化情境 | 材料在什么条件下呈现不同内容 | 差异可寻址，不把情境升级为已确认因果 |
| 差异、争议与边界 | 材料为何不同，哪里仍冲突 | 明确共同对象、差异轴与不可比处 |
| 规律性特征 | 有哪些结构性关系或跨材料条件性模式 | 类型、前提或条件、材料、相反内容和边界齐全 |
| 未知 | 当前体系在哪些地方不能回答 | 缺口及所需新材料类型明确 |

## 范围内基线

范围内基线包含两种互斥状态：

- 闭合事实：在明确版本、文本、代码、定义或来源身份边界内可直接核对的命题。例如“版本 V 的文件 F 定义了模块 M”。它不能外推到线上配置、其它版本或现实效果。
- 跨材料一致呈现：可比材料在明示集合、口径和观察范围内共同报告的内容。例如“所查三份材料都报告检索与长期存储分离”。只能写成材料集合的共同呈现，不能改写成领域现实命题为真。

开放现实主张包括疗效、客观效果、机制因果、社会结果、经验优劣和个体适用性等需要超出来源内容作现实裁决的命题。本 Skill 只还原谁作出这些主张、依据和范围是什么，以及材料间怎样一致或冲突。

## 规律性特征

### 结构性关系

结构性关系由定义、静态代码结构、状态机、合同/制度条款或公式在明示前提下直接推出。记录：前提、推导链、来源版本、适用范围和不可推出内容。它不说明经验频率、客观效果、运行时事实或现实因果。

### 条件性模式

每条模式写成：

> 在所查材料范围 S 与材料所述条件 C 内，A 与 B 反复呈现关系 R；呈现该关系的材料 E；作者机制/因果主张状态 M；相反或例外材料 X；重查条件 F。

- S：被实际查阅且可比较的材料集合、人群、产品、时间、地域或版本。
- C：材料中用于区分呈现差异的条件，不由本 Skill 确认为现实因果变量。
- R：共同出现、相关、先后或分化，不写成本 Skill 确认的因果。
- E：至少两张可寻址、可比较材料卡。
- M：哪些作者作了何种机制或因果主张、设计基础为何；本 Skill 不裁决该主张成立。
- X：相反观察、异常、不可比材料或覆盖空白。
- F：哪些新材料会要求模式拆分、降级或重查。

规律性特征的用途是压缩理解，不是压缩用户的选择空间。不能把“材料在这些条件下反复报告某结果”改写成“所以现实中应采用某方法”。

## 描述性对照与决策性比较

允许描述性对照：按来源可核对的中性轴并列已有对象变体，例如组成、实施步骤、样本、材料报告结果和失败现象。它帮助读者看懂研究对象。

禁止决策性比较：为替现实选择服务而设定总体效用、好坏、优先级、纳入/排除、胜负、推荐或默认价值权重。即使不写“推荐”，把多个维度合成为总体优劣也属于越权。

## 争议归纳

- 确认共同对象和共同问题。
- 找差异轴：定义、指标、样本、阶段、实施方式、时间、版本或职责性权威。
- 将材料可见的差异按条件分组，不把分组解释成已确认因果。
- 将仍无法解释的部分保留为实质冲突或不可比较。
- 指出推进理解需要何种新材料，不判定哪方胜出。

## 主线认知叙事

```mermaid
flowchart LR
  A["对象骨架"] --> B["范围内基线"]
  B --> C["关键分化情境"]
  C --> D["差异、争议与边界"]
  D --> E["规律性特征"]
  E --> F["未知与重查条件"]
```

这个顺序不是固定章节模板；若对象需要先解释一个承重情境才能理解骨架，可以调整局部顺序，但必须保留认知依赖。每个承重陈述有四级追溯：叙事段落 → 信息层或特征 ID → 材料卡 → 原始来源。

## 防止隐性推荐

- 不用“更成熟、显然、理想、值得、首选”等价值词替代材料描述。
- 各对象篇幅由解释需要决定；篇幅不构成推荐等级。
- 不默认某种价值取向或现实情境替用户筛选材料。
- 材料中的建议标明提出者、对象、依据和边界，不转写为报告建议。
- 结尾不收束成行动序列，只收束认知全貌、规律性特征边界和未知。

# 完成、停止、回开与失效重开

## 调用契约

- 使用时机：任一阶段判断是否停止某路径、是否放行；N5 定位消费失败；已放行研究因外部变化重新打开。
- 输入：当前阶段产物、完成标准、消费测试证据、来源状态变化。
- 输出：继续、停止局部查询、放行、精确回开、失效重开或分流。
- 不负责：用检查清单替代真实取证或下游行为测试。

## 局部停止不等于研究完成

单条查询路径可在以下情况停止：

- 新材料只重复已有证据，不再改变当前分支。
- 已达到与风险相称的证据强度。
- 当前渠道不能消解缺口，且替代路径已尝试；缺口被明确保留。
- 继续搜索的预期信息价值低于成本或风险。

其它承重任务、候选覆盖和下游消费仍需分别闭合。

## 回开路由

| 失败信号 | 责任节点 |
| --- | --- |
| 主体、情境、时间、目标判断、安全或决定权改变 | N1 |
| 缺概念、关系、竞争模型、适用性，或产生新证据需求 | N2 |
| 已有取证任务的来源失效、不可达或强度不足 | N3 |
| 缺候选、排除理由、来源关系或候选覆盖 | N4X |
| 候选已有，但比较条件、翻转因素或表达不可消费 | N4 |
| 测试设计不能代表真实用途 | N5 内重设计消费任务 |

回开必须携带：失败证据、受影响主张/字段、责任节点和重新放行条件。不得只写“继续调研”。

## 当前版本完成

只有同时满足以下条件才可放行：

- 判断对象闭合：用户知道当前版本研究的对象、范围和决定权。
- 承重主张闭合：来源、适用条件、证据类型和强度可追溯。
- 材料到选择的关系闭合：候选从现实关系生成，比较不依赖隐藏价值。
- 未知被压缩：剩余未知是具体缺口或风险边界，不是宽泛领域空白。
- 独立消费者能只凭交付物说出下一步、依据与条件、不可判断项、补问信息和失效条件。

完成不等于没有未知，也不等于真实行动已经成功。研究可以放行“先做一次可逆实验”或“向专业人员核实这组三个问题”，但不能冒充实验、治疗、购买或注册已经验证。

## 失效重开

已放行主张在以下变化后重新成为待调查问题：

- 来源撤回、修订、过期或无法重现。
- 产品版本、价格、政策、地域规则或外部环境变化。
- 用户主体、目标、风险或资源变化。
- 真实执行结果与模型预测冲突。

失效重开时先定位受影响主张和下游候选；只重做受影响链条，除非变化触及 N1 核心字段。

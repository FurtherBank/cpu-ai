# 完成、停止与精确回开

## 局部搜索停止

一个调查任务只有同时满足以下条件才停止：

- 已取得能说明材料身份、原意和覆盖范围的可追溯来源，或明确记录为何不可得。
- 已覆盖该任务要求的主要情境、差异轴、反例或限制。
- 新一轮材料只重复已有主张，不再改变六层归类、规律边界、冲突结构或未知状态。
- 仍有缺口时，缺口已被准确命名，而非用“资料不足”笼统代替。

停止是注意力配置结论，不表示材料中的开放现实主张已被证真。

## 全局完成

- 研究对象契约稳定，近敌和排除项清楚。
- 探索模型的承重关系均已被材料覆盖或标为未知。
- 六层信息体系均已检查；缺层有可解释原因，不强行补齐。
- 每项范围内基线和规律性特征可追到认识状态、材料、范围、相反内容和重查条件。
- 争议已拆成差异轴、条件分支、实质冲突或不可比状态。
- 主线认知叙事能让独立读者以最简单清晰的方式重建全貌。
- 报告没有生成、总体评价、筛选、排序或推荐现实方案，也没有开放现实主张真假、客观有效性或个体适用性裁决；已有对象变体的描述性对照使用中性可观察轴。
- N6 独立理解测试通过。

## 精确回开

| 失效表现 | 回开节点 |
| --- | --- |
| 对象、近敌、范围或受众粒度错误 | N1 |
| 缺少关键概念、关系、情境或调查任务 | N2 |
| 来源不可追溯、原意失真、材料直接覆盖范围或冲突关系错误 | N3 |
| 六层错分、闭合事实越界、模式脱离材料范围/无相反内容或争议被抹平 | N4 |
| 阅读顺序失真、术语难懂、追溯断裂或隐性推荐 | N5 |
| 独立读者无法重建、归类给定片段、解释争议或追溯 | 先按失败原因定位 N1–N5，再重跑 N6 |

不得用“再多搜一点”代替定位。只重开受影响节点及其下游，但必须记录版本影响。

## 失效后重开

以下变化会使已完成研究重新成为待查：关键来源更新或撤回；法规、指南、产品版本或实现变化；新增材料打破既有规律；用户扩展人群、地域、时间或对象；独立读者发现隐性裁决或关键情境缺失。先定位受影响的事实、规律和叙事段落，再决定搜索范围。

# investigation-research：行为日志可比对质量标准

> 供运行时审计与后续契约偏差检测消费。

## 结构完整性

- [ ] 日志位于 `.skill-logs/investigation-research/yyyy-mm-dd/hhmm-*.md`
- [ ] 元数据表含 `规范版本: behavior-log/v1`、执行 ID、Skill、状态、时间、工作区、执行目标
- [ ] behavior-log/v1 的 11 个固定章节齐全且顺序正确
- [ ] 封口后无“执行中，待收敛”类占位符
- [ ] 日志进入终态后，“影响清单”和“结果与验证”不得残留 `执行中`、`待定` 等进行态；未完成项必须改写为与顶层终态一致的 `未完成`、`待复测` 或 `不适用`
- [ ] 开始、最后更新和完成时间来自实际系统时钟，满足开始 ≤ 最后更新 ≤ 完成，且不晚于实际封口时刻
- [ ] N5 前取消、阻断或失败时仍已封口；摘要写明已到达/未完成阶段，现有研究制品明确标为未放行，并给出恢复入口

## 阶段覆盖（Audit Hook）

| 阶段 | 日志须更新的章节 | 完成判据 |
| --- | --- | --- |
| N1 定界现实问题 | 依据与关键输入、关键行为；必要时影响清单、偏离/未决事项 | 契约版本、分流和决定权有记录 |
| N2 建立模型与取证任务 | 关键行为、资源索引；持久化时影响清单 | 模型版本和取证任务产物可寻址 |
| N3 取得并裁定材料 | 关键行为、影响清单、资源索引、子 Skill 调用 | 承重查询、子调用、模型回写和来源制品可追溯 |
| N4X 生成候选空间 | 关键行为；持久化时影响清单、资源索引 | 候选版本、权限分层和回开有记录 |
| N4 形成判断接口 | 关键行为、影响清单、资源索引、结果与验证 | 报告路径及静态校验结果已记录 |
| N5 独立试用并放行 | 关键行为、结果与验证、偏离/未决事项 | 测试证据、失败回开和最终状态已记录 |

## 子 Skill 链

- [ ] 每个显式 Skill 子调用在“子 Skill 调用”表登记
- [ ] 子日志链接可访问且为 workspace-relative
- [ ] 子 Skill 材料性影响已汇总进父“影响清单”
- [ ] 纯 Task 委派在父“关键行为”至少有一行输入、结果和影响摘要

## 影响闭包

- [ ] “影响清单”覆盖研究报告、中间账、行为日志及外部系统材料性动作
- [ ] 明确记录未执行的治疗、购买、注册、部署或其它现实行动
- [ ] 顶层执行摘要覆盖整个执行链主要影响，不把拟执行写成已执行

## 与交付物对齐

- [ ] 研究报告路径出现在“资源索引”，日志不复制报告正文
- [ ] 中间账若持久化，其路径和版本与最终报告引用一致
- [ ] 已到达 N5、报告具备交付条件但仅因环境没有独立测试能力而未测试时，最终状态只能记 `部分成功—待独立测试`，并记录测试输入包和恢复入口；N5 前取消、阻断或失败按实际终态封口，不套用本条
- [ ] 所有失败、部分成功、分流或待专业核实状态在摘要和未决事项中一致

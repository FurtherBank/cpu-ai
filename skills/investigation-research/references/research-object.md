# 研究对象与分流

## 调用契约

- 使用时机：N1 需要把用户提问定界、拆分、换版或分流时。
- 输入：用户原话、现实情境、期待结果、风险与权限。
- 输出：现实问题—判断单元所需字段，以及继续、澄清、拆分或分流的事实依据。
- 不负责：搜索材料、形成诊断/建议、替用户或专业人员决定。

## 现实问题—判断单元

一个有效研究对象同时包含：

- 原始问题：用户实际如何表述，保留可追溯性。
- 当前现象或目标：现实中发生了什么，或想改变什么。
- 主体与情境：对谁、在什么环境、地域、资源和约束下。
- 时间尺度：现在、某一事件窗口、长期，或结论有效期。
- 待支持判断：调研之后准备选择、解释、验证或询问什么。
- 重要结果：判断需要改善或保护什么。
- 不可接受后果：错判会造成什么损失或风险。
- 决定权：Skill、用户、组织角色或专业人员分别能决定什么。
- 排除项：本轮明确不解决什么。
- 完成标准：下游凭交付物要能完成什么。

主题相同不代表研究对象相同。“大模型记忆有哪些技术”和“某客服产品是否需要跨会话记忆”具有不同主体、结果和完成标准，应建立不同判断单元。

## 最少澄清原则

只追问会改变以下任一项的信息：

- 安全与是否允许继续。
- 研究对象或所需证据体系。
- 候选方向的合法性或适用性。
- 判断的价值权重和决定者。
- 完成标准。

其余未知可以保留为条件分支，避免把研究启动变成长问卷。

## 分流矩阵

| 识别状态 | 处理 |
| --- | --- |
| 存在紧急危险、强制截止或继续研究会延误必要处置 | 停止；整理已知事实和需立即交给有权限者的问题 |
| 只需一个稳定、单一、可直接核验的事实 | 转简单查询 |
| 已有明确方案，目标是执行、实施或修复 | 转相应执行流程 |
| 核心缺口只能通过真实实验/测量获得 | 调研可设计实验或信息接口，但真实执行另行授权 |
| 必须由医疗、法律、税务或组织角色裁定 | 调研只准备证据、条件和核实问题，不形成越权决定 |
| 一个问句包含多个不同决定者或证据体系 | 拆分为多个相互引用的判断单元 |

## 换版规则

主体、情境、时间尺度、待支持判断、重要结果、安全约束或决定权发生变化时，创建新版本并说明继承与失效内容。不要静默改写旧研究对象。

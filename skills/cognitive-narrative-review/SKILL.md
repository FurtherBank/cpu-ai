# 如何鉴别认知叙事的文本引导是否带偏读者

> 不是问“这篇文章有没有说服力”，而是问：它让读者暂信了什么、停止检查什么、优先走向哪条路；这些定向究竟有没有取得相应的资格。

一篇文章读起来很顺，甚至让读者频频点头，仍可能存在一种更深的失败：读者被带到了一个结论，却不知道自己在哪一处放弃了别的可能、为什么有资格放弃，以及何时应该回头。

这种失败不总表现为一句明显错误的话。一个标题、一段先后顺序、一个“只有”、一个被藏到后文的限定，甚至一处没有写出的桥，都可能让读者的后续思路改道。若只查事实、语法或作者有没有显性下结论，就会错过真正让整篇文章走向偏移的东西。

本文讨论的正是这种对象：怎样识别认知叙事中影响读者走向的定向关系，怎样判断它的质量，以及怎样用生成型的 Subagent 审读发现问题，而不是把“文章顺”“读者赞同”误当成验证。

这里的**认知叙事**，指面向一类已界定读者、为完成解释、比较、判断或决策支持任务而组织问题、材料、推理、条件和回收的文本。本文主要适用于解释、论证、分析、教学、方案与决策支持；纯检索条目、即时警示和以审美体验为主的文本，可以只借用其中的定位、条件和回查原则，而不必展开完整路径。

## 本文的边界：审文本怎样引导，不裁定内容模型

本文只审文本是否有资格把读者带过一条理解路径：它定位读者状态、承载物、被打开或压低的路线、文本中的桥与停止条件。它不独自裁定一个定义、节点、因果、必要性、价值取舍或授权关系在现实中应当取什么值。

遇到“所有、只有、必须、必经、唯一、充分、必然”等承重内容关系，或关系的范围、现实依据、价值／权源资格会改变多个下游时，本文只提交一张**研究问题卡**，交给[$research-content-judgment](../research-content-judgment/SKILL.md)。该 Skill 独立研究真实约束、竞争模型和关系级裁定；本文收到其内容裁定后，才重跑受影响的读者路径。

```text
研究问题卡
文本版本与位置（没有文本时为空）：
候选关系 R 及原文声称的量词／强度：
原始范围 D、承重理由与具名下游影响：
最近仍成立的替代路线：
原文调用的材料、价值或权源，以及来源状态：
待裁决的精确问题：
```

这张卡只说明“为什么值得研究”，不把原文主张、读者误解或作者偏好当作现实事实、硬约束或价值裁定。

**内容裁定卡**由研究性内容判断产生，字段与版本规则以该文的“输入、输出与独立使用”为准。文本审查者只消费其中已经裁定的关系、范围、操作、未知和重开条件；不能自行填写或把文本问题升级为内容裁定。

## 先看清我们在审什么

[《判断的质量》](../judgement/判断的质量.md)把“判断”定义为主体在不能立刻闭合真伪、却必须继续前进时，对后续认知资源作出的方向承诺。它发生在主体的计算图里：决定接下来注意什么、默认什么、不再复检什么。

文章审读不能直接审作者心里是否真的作出过这种判断。作者意图不可见，读者也不需要靠猜作者内心来理解文章。我们能审的是文本的可观察效果：在一个明确的读者契约下，哪一处文字或结构使读者的理解状态发生了变化。

本文把这个对象叫作**读者状态定向关系**。

说白了，它就是“这处文本实际把读者带到哪里，又让他暂时不再走哪条原本还可能成立的路”。

一条读者状态定向关系可以写成：

```text
R = <C_契约, S前, K, S后, A1…An>

C_契约：冻结的读者契约、当前任务、已见文本与允许使用的材料
S前：读者在此处之前暂时知道什么、应优先什么、谁被允许作何行动、还缺什么、哪些路仍开着
K：承担定向作用的句群、标题、限定、例子、顺序或局部关系
S后：读者更新后暂信什么、应优先什么、谁被允许作何行动、结论到什么强度、下一步可进入什么分支
A1…An：与原路线距离相同或相近、仍可成立、但被 K 降低优先级或关闭的替代路线；若 K 只打开或示范一条路，则此项可以为空
```

这里的“冻结”不是假装所有读者一样，而是先明确这一次要审谁、他带着什么前提进入、要完成什么理解任务。没有这个契约，就无法分辨一处转折到底是必要引导，还是作者偏好的顺手调度。

状态中的三类“可以”必须分开：**认识上可暂信**，是材料目前支持到什么强度；**规范上应优先**，是在目标与约束下推荐哪条路；**治理上被允许行动**，是谁在何种范围内真的有权决定或执行。它们不能互相推出。

当 `K` 写出“只有”“必须”“应优先”之类的压低或关闭时，审计者不能随手挑一条替代路线。默认只需写出一条足以改变当前判断的最近替代：它服务同一任务、共享大部分已声明前提，并在一个关键差异上偏离原路线；若目标与范围等条件无法拆开，就允许记录为一个**不可拆分的最小耦合差异**，而不是假装路线不足。只有这条路线仍答不清第三、四问、审读者发生分歧，或关系已进入主干复核时，才冻结完整候选集，记录并列路线、新增假设、改走后果、距离与淘汰依据。若当前材料仍不足以构造替代，应记录“替代路线不足”，不能把它误写成“原文已经排除了所有替代”。“未证闭合”针对升级后仍未排除的相关候选，而不是审计者碰巧挑中的一条。

## 默认只问五个问题

绝大多数审读不需要先把全文拆成一套复杂系统。先沿着一条候选关系问完下面五问；它们按读者实际会经历的顺序排列。能答清五问，通常已经能决定这处应保留、补条件、分路，还是暂缓结论。

| 问题 | 要写出的最小答案 | 答不出来时的正确处理 |
| --- | --- | --- |
| **读者被带到哪里？** | `S前 → S后`：他现在多暂信了什么、多能做什么，或少检查什么 | 找不到实际变化，就不把它当作定向问题；找不到完成任务所需的更新，则记录转移缺口。 |
| **它在打开、排序，还是关掉哪条路？** | 先标明 `K` 是示范／打开、排序，还是压低／关闭；仅后两者写一条最近替代路线 | 只打开一条路时，检查范围和仍保持开放的条件，不强迫它排除近路；压低或关闭时不能构造候选，就写“替代路线不足”。 |
| **凭什么可以这样引导？** | 它在回答定义、事实／因果、价值／设计、授权／治理中的哪一个问题，或哪些问题 | 理由混在一起时拆开；还没有独立依据时报告未证闭合、价值未显露或授权未知。 |
| **何时必须重开？** | 一个会让这次转向暂停、降级或改走的条件 | 没有停止条件，结论只能保留为暂定；若读者连桥在哪里都找不到，报告结构失败。 |
| **它会把整篇带偏吗？** | 它影响的具名下游转移，以及是否难以低成本回收 | 影响入口、核心对象、关键前提或多条下游时升为主干；其余先作为关键分叉或枝叶处理。 |

说白了：先看**带到哪里**、**它是在打开、排序还是关路**、**为什么有资格这样引导**、**什么情况下要重开**、**这件事有多大**。这不是另一张检查清单；它是把一次审读收束为一个可随时暂停的最小判断。

基本情况也由此自然分流：没有变化，就不追；有变化却没有文本桥，是结构失败；文本只打开一条路，就检查它的范围和开放条件；文本压低近路却不能说明资格，才是未证闭合；取舍没有显露，是价值未显露；主体和权限说不清，是授权未知；只有找到可定位的击败锚点，才报告它在当前范围内不成立。多个句子共同承重时，把它们当成一个复合 `K`，不要因单句测试不显著而漏掉它。读者契约本身不清楚时，先重冻契约，不能继续审。

## 不要把几个近邻混成同一个对象

读者状态定向关系不是一句“判断句”的同义词。

- **事实陈述**只有在它改变读者暂信内容、结论强度或可走分支时，才进入这次审计。没有外部材料时，审计只能说“本文不足以让它承担这个定向角色”，不能据此断言现实事实为假。
- **显性结论**经常是定向关系的一部分，但并不必然承重。一句结论若只是回收已建立的理解，未改变读者下一步，它不一定是本轮的重点。
- **定向承载物**是 `K` 的文本侧名字：已经在文本中承担定向的句群、标题、限定或结构关系。它不是总称，因为有时读者需要完成一次更新，文本却找不到任何东西承担它。
- **转移缺口**是后一种情况：从前一个理解状态到完成任务所需的下一个状态，本应有一次更新，但读者只能靠外部知识、作者意图或后文回填来跳过去。
- **普通表达问题**如错别字、句子拗口、例子不够漂亮，只有在受控替换后改变读者的任务、结论范围、可依赖前提或可走分支时，才升级成定向问题。否则它们是枝叶，不该抢走主干审读的注意力。

这一区分尤其重要。一个“因此只能选 A”可能确实把读者带向 A；它有定向承载物。但如果文本没有给出材料、推理、条件或授权，使“只能”成立，问题是**坏桥**，不是“没有桥”。反过来，如果读者根本说不出为什么现在要从前文进入后文，才是转移缺口。

读者状态定向关系是审计对象；转移缺口则是“完成任务所需的关系没有被文本承载”的结构失败状态。记录缺口时，应写清缺的是哪一次更新、发生在哪个 `[n]→[n+1]` 边界，而不是假装那里存在一个尚未找到的 `K`。

## 怎样证明一处文本真的在定向

不能因为一句话听起来强势，就认定它影响了认知走向。第一问没有争议时，写清 `S前 → S后` 已足够继续；当有人质疑这处是否承重、或它要进入主干时，再用受控近反事实取得最小证据。

先让读者只看到截止当前位置的文本，恢复四件事：当前要解决什么问题；暂时能依赖什么；结论能到什么强度；下一步允许走什么。然后保持读者契约和其余材料不变，只删除、弱化、调换或改写候选 `K` 的关系、条件、顺序或承诺力度。

每次近反事实都要同时给出一个**中性对照版本**：它保持语法连贯、指代完整和所有非定向信息，只改变这次要检验的桥、条件、顺序或承诺强度。否则，删掉 `K` 后的混乱可能只是句子坏了，而不是读者被重新定向。对复合 `K`，还要记录成员范围、联合替换结果和单项替换结果；单项不显著而联合显著，不能被当作枝叶放弃。

如果读者的当前问题、可暂信前提、应优先路线、授权理解、结论范围或下一分支至少有一项发生实质变化，`K` 与这次状态变化就构成读者状态定向关系。“实质”不是读起来换了腔调，而是读者会据此多做、少做、暂缓或改走一个不同的后续判断。若单点替换没有变化，也不能立刻把它降为枝叶：相邻句群、重复的同向省略或跨段顺序可能共同构成一个复合 `K`，应记录为待定位的复合关系。

一个微型例子：前文只给出“访谈对象都是新用户”，后文写“因此当前证据只支持新用户的判断，老用户仍需另查”。把“只支持新用户、老用户仍需另查”改成“当前证据已证明所有用户”，读者的结论范围与下一项研究都会改变；这不是文风差异，而是经验性定向。若多处都轻描淡写地把“当前样本”写成“用户”，单独删任一句未必改变状态，也应把这组省略作为复合关系审查。

这个测试不是要证明真实人群一定会如此反应。它只验证：在已声明的读者契约下，文本有没有把一条理解路径实际写出来。真实效果仍需要目标读者完成重建、定位、异议和迁移任务后才能判断。

## 引导资格答不清时，转成内容研究问题

五问中的前三问足以定位大多数文本问题：读者状态、路线是被打开／排序／压低，以及文本为何声称可以这样做。这里若发现理由混合或无法闭合，下一步不是在本文中补一套内容裁定，而是把问题写成可研究的关系，交给[$research-content-judgment](../research-content-judgment/SKILL.md)。

下表只帮助审读者把“文本哪里要求读者接受什么”翻译为研究问题；它不是内容义务表，也不在这里决定答案。

| 文本中声称的资格 | 应交出的研究问题 |
| --- | --- |
| 定义 | 这个边界是约定、描述还是分类主张？它应覆盖和排除哪些对象？ |
| 经验／因果 | 哪些真实机制或事实支持这条关系到当前强度？是否存在保约束的竞争解释？ |
| 规范／设计 | 哪个目标、代价或硬约束使这条路线胜出？这些取舍由谁裁定？ |
| 授权／治理 | 谁可在什么事项、范围、程序和时效内作出这个决定？权源是什么？ |
| 复合或未分类 | 哪些互不推出的子关系被压进同一句？需要分别研究什么？ |

例如，“因为数据显示 X，所以部门必须采用 A”在文本层面可能同时把读者带过经验、规范和授权三次更新。本文要报告的是这三次更新有没有被看见、是否被一句自然语言偷渡；内容文档才研究数据、取舍和权源各自能否成立。

这样，文本审查不会用“证据很强”替读者遮住价值取舍，也不会用“方案合理”替内容研究跳过授权边界。

## 文本审计能报告什么，不能报告什么

文章有一处未写出的条件，并不自动说明它错了。作者可能掌握了文外材料，读者也可能已从入口契约获得某个前提。把所有未写出的内容都宣判为错误，和把流畅当正确一样粗糙。

在本文约定的、可复查的**文本审计报告**中，只有存在**击败锚点**，才有资格说一条定向关系在当前文本范围内不成立。这里的“不成立”只指文本自己的桥、明示前提或已引入材料无法支持这次读者转向；它不是对现实内容模型的终局裁定。

击败锚点不是“我不同意”，而是能直接让这次**文本转向**失效的可定位依据，例如：文内前后矛盾；在文本明示前提下推理无效；违反文章已声明、且已作为读者契约一部分的硬约束；或文章自己的权源说明前后冲突。独立材料、真实权源或现实经验若与文章冲突，只能提交研究问题卡，不能在本文直接变成内容裁定。

没有这类锚点时，审计应保留不同的结论状态：

| 结论状态 | 应当怎样报告 |
| --- | --- |
| 被击败 | “这处定向与锚点 X 冲突，因此在范围 Y 内不能由本文现有桥支撑。” |
| 未证闭合 | “当前文本不足以支持这次排序或排除相关替代路线 A1…An；应显露未知或提交研究问题。” |
| 价值未显露 | “推荐依赖目标或代价权重 Z；文章应显露取舍，并把其取值交给内容判断或决定者。” |
| 授权未知 | “这些句子不足以让读者理解‘必须’或‘只有’的权源；应提交授权研究问题。” |
| 结构失败 | “读者无法定位这次更新的承载物、推理桥或停止条件。” |

这种纪律不是保守措辞，而是防止审计者把自己的偏好伪装成事实反证。文本侧修复可以使未知、条件、分路和权源缺口对读者可见；它不能伪造一个内容答案。内容裁定返回后，才决定应保留、删除、迁移还是条件化哪条关系。

## 主干高风险或五问不能闭合时，才让失败自动显形

[《判断的质量》](../judgement/判断的质量.md)指出两个共同陷阱：测试和判断来自同一张信念网络，或人把“流畅、完成、一致、获得认可”的感觉误当成区分度信号。于是，“请作者自查”“请 AI 判断我对不对”“读者说很有道理”都不足以验证定向质量。

当五问已经显示“主干在这里承重”或“排序／关闭资格、停止条件不能闭合”时，才升级为生成型审读。代理不应知道作者选了什么结论，而应在冻结输入下生成另一件可以与原文对照的东西。这不声称已经给出探针的经验可靠性排名；它只让“哪里不一致、哪里不能重算、哪条路线仍未排除”更难被一句流畅认可掩盖。下表检验的是**文本已给材料能否使读者重建关系**，不是借 Subagent 裁定现实事实、价值取舍或权源；后者必须转交内容研究。下表是升级菜单，不是逐句必跑的流程。

| 工件或探针 | 它让什么自动显形 | 适合审什么 | 重要边界 |
| --- | --- | --- | --- |
| 结论盲的文本内扰动重算 | 敲掉一个承重前提后，原文明确调用的材料还能支持什么强度 | 经验／因果桥的可重建性 | 只给原文明确调用的材料；不做外部事实核查。 |
| 匿名近路重建 | 在当前文本材料下，读者还会看到哪条相近路线没有被文内理由关闭 | 分支关闭的可见性 | 只报告文内仍开放的路线，不裁定哪条路线在现实中胜出。 |
| 文本来源地图 | 读者能否定位每条材料来自哪里、文章是否把不同类型材料混成一个依据 | 经验性定向的可追溯性 | 不核验来源独立性或材料真实性；这些问题交内容研究。 |
| 定义可见性替换 | 换掉文章的边界表述后，读者是否失去文内必要区分，或成员资格是否前后冲突 | 定义性定向 | 不裁定哪种定义在现实中最好。 |
| 权源主张定位 | 读者能否找出文章声称谁、依据什么、在何范围内有权决定 | 授权／治理定向的可定位性 | 不核验实际权源；无法确认时提交授权研究问题。 |
| 盲迁移接力 | 从文章提取出的模型，能否在只改变一项条件的新情境中说明为何改走 | 终态能力与停止条件 | 失败不自动证明真实读者都不懂；情境不足时应记录为未定。 |

这些探针不需要逐项套在所有句子上。它们的价值来自“反过来生成一个可能使原文失败的对象”，而不是把作者已知结论重新讲得更漂亮。

## 注意力先投向整篇会转向的地方

审读的目标不是制造最长的问题清单，而是让整篇认知路径走向更好。因此，先看一个问题会影响多少后续转移、会不会过早关闭关键路线、错了之后是否难以回收。

| 优先级 | 典型位置 | 处理方式 |
| --- | --- | --- |
| 主干定向 | 入口任务、核心对象、主结论、关键前提、多个下游共用的桥 | 先答五问；文本桥、停止条件仍不能闭合时选一个最有区分力的文本探针；关系本身的范围、现实依据、价值或权源不明时，同时提交研究问题卡。未澄清前，不接受下游局部顺畅作为背书。 |
| 关键分叉 | 一个重要条件、竞争解释、价值取舍或行动入口 | 主干稳定后，重点检查读者能否看到分叉、停止条件与改走后果；价值或权源本身待内容研究裁定。 |
| 枝叶 | 局部措辞、例子或检索便利 | 记录后暂缓；只有累计遮蔽主干，或实际承担转向作用时才升级。 |

一个候选能否进入主干，不凭“这句话看起来很重要”。应写一个带中性对照的最小反事实：只替换这一处或这一组复合承载物，读者哪一项状态变了、哪组具名下游转移失去依据、哪条具名分支重新打开或关闭，以及偏离后是否难以在下游便宜地回收。没有这张映射，局部表达问题不应抢走主干注意力；反过来，入口任务、核心对象和关键前提的断裂，即使还没有清晰的替代路线，也不能以“不是活分叉”为由排除。

## 把一次审计真正跑起来

默认路径只有四步。

1. **冻结这次读者。** 写下 `C_契约`：谁来读、带着什么前提、要完成什么任务、可以看什么材料，以及文本版本。契约不清，先停下补它。
2. **先审会改动主干的地方。** 圈出入口任务、核心对象、关键前提、主结论、行动入口和共用桥；对每一处只回答五问。若承重性存在争议，或候选要进入主干，先做中性最小反事实，确认它真的改变读者状态与具名下游；这是一道定位门槛，不是额外的 Subagent 升级。未影响这些位置的内容先不占用注意力。
3. **按状态最小回开，并转交内容问题。** 有文本击败锚点才说这次转向不能由本文现有桥支撑；其余按“未证闭合、价值未显露、授权未知、结构失败或替代路线不足”报告。凡涉及关系本身的范围、现实依据、价值取值或权源，附上研究问题卡。文本修复只做最早失效处的定位、条件可见化、分路、未知标识或停止规则，不自行补造事实与结论。
4. **先消费内容裁定，再重跑受影响的下游。** 内容裁定卡若删除、合并、迁移或条件化关系，重看依赖它的入口、桥、分支、结论与探针；只有纯文本修复时才可直接重跑。枝叶问题可以暂存，不能反过来作为主干正确的证据。

在上一步已经确认承重之后，只有出现下列情形，才增加一个生成型升级动作：主干关系的文本桥或停止条件答不清；多句可能共同承重；或修复后下游仍出现相互矛盾的理解。此时选**一个**最贴合文本缺口的生成型探针，而不是把整张表跑完。若问题是内容关系本身不明，Subagent 只可协助产出研究问题卡，不能越权下内容结论。给 Subagent 的输入要冻结到它完成任务所需的最小范围，并隐藏作者结论；例如入口—对象测试只给已有前提和开头切片，让代理从文本定位对象、任务、范围和终态，再由主控与隐藏契约比对。无原文定位就记录入口缺口，不能让代理复述主持人给出的答案。

## 用创造性工作流导读做一次实验

《理解创造性工作：从未知到可回开的承诺循环》是一个很好的压力样本：它主动区分现实、方向、设计、规划、实现与反馈，也反复强调证据不能取代价值、协同不能取代授权。正因如此，问题不在它有没有概念，而在某些概念怎样改变读者的下一步。

### 开头的工作模型会不会被读成创造性工作的无条件本体

本实验冻结的读者契约是：读者要用样例理解并设计创造性工作流，会读一般分析文章，但不拥有链接页面、实际项目事实或真实授权材料。可直接审的最小片段是：

> “创造性工作不是‘把一个已知目标拆成步骤并完成’……由主体借助证据与协同，反复学习、判断、授权、兑现改变，并接受反馈的承诺循环。”
>
> “一个程序、原型、知识资产或流水线可能技术上成立，却仍可能回答错了真实问题……或没有给实际使用者带来价值。”
>
> “这份叙事只说明当前工作定义如何相互解释……目录自身仍将整体有效性视为 `INDETERMINATE`。”

前两句在样例第 9–11 行，最后一句在第 91 行；`INDETERMINATE` 在这里仅指“当前无法判定方法论整体是否有效”。相关原文见[样例开头](</Users/a1111/Desktop/ai-workspace/⭐️ cognition/创造性工作流/理解创造性工作：从未知到可回开的承诺循环.md:9>)与[当前边界](</Users/a1111/Desktop/ai-workspace/⭐️ cognition/创造性工作流/理解创造性工作：从未知到可回开的承诺循环.md:91>)。

这处的读者状态定向关系是：从“已知目标执行与未知、价值未决工作都还需区分”，转到“承诺循环是创造性工作的必要本体，实例完成普遍不足”。最近仍可成立的路线是：承诺循环是处理现实、价值、路径或授权尚未闭合的创造性任务的工作模型；已获方向、局部且可逆的工作应被分流或明确置于范围外。

只把“创造性工作不是……”改成“本文把仍含现实、价值或路径未知的创造性工作界定为……”，其他内容不动，就会重新打开这条路线。这个近反事实说明开头确实在承重。

对这个冻结片段，已检查但没有找到的击败锚点是：它没有在文内明确宣称“承诺循环已经被现实证实为所有创造性工作的唯一机制”；开头定义与末尾“当前工作定义／整体未定”也不构成直接逻辑矛盾。它仍没有在定向发生处给出足以排除范围受限替代路线的桥。因此正确报告不是“定义错了”，而是：**该主干定向尚未闭合，且价值取舍与适用范围应更早显露。**

### `C` 样例：文本审计在研究问题处停止

`C_承诺` 是样例图中的“主体承诺”：有权者给出可供下游依赖的方向范围。它与前文的 `C_契约` 没有继承关系；前者是被审文本中的候选节点，后者是审计输入。样例可直接审的最小片段是：“一个分支要真正成为下游可以依赖的方向，必须经过方向承诺：有权者……作出可追溯答复”与“只有 `C` 才让设计和规划知道‘目前可以在什么范围内认真投入’”。原文见[方向承诺](</Users/a1111/Desktop/ai-workspace/⭐️ cognition/创造性工作流/理解创造性工作：从未知到可回开的承诺循环.md:35>)、[Agent 边界](</Users/a1111/Desktop/ai-workspace/⭐️ cognition/创造性工作流/理解创造性工作：从未知到可回开的承诺循环.md:67>)与[运行入口](</Users/a1111/Desktop/ai-workspace/⭐️ cognition/创造性工作流/理解创造性工作：从未知到可回开的承诺循环.md:73>)。

文本审计能确认的只有：这两句把读者从“方向、设计和规划之间可能存在多种衔接关系”，带到“设计和规划的可依赖方向只能经过 `C`”；它关闭的是“不设独立 `C` 节点，而把授权、范围、资源、回流和验收分别写进实际行动关系”的近路。这个关闭影响多个下游，因而是主干定向。

至此应交出研究问题卡，而不是在文本审计中替 `C` 补例外或直接辩护：

```text
候选关系 R：在范围 D 内，所有可供设计和规划依赖的方向都必须经过独立节点 C。
原始范围 D：样例声称的创造性工作流，而非先行缩窄后的受限探索。
保护约束：不得让无权主体替代价值决定；方向、投入和回收须可追溯。
待裁决：删除 C 后，能否由实际行动关系分别承接这些保护约束，并在相关情境中运行？
```

这张卡不预设“`C` 很重要”，也不预设“探索必须被放行”。它要求内容研究比较保留 `C`、删除 `C`、将其功能迁移到具体关系或任务记录等模型。若返回的内容裁定是“删除／拆解”，文本侧的后续工作是移除把 `C` 写成全局必经入口的桥，并逐处写清承接后的授权、范围、资源、回流与验收关系；然后重跑读者路径，确认读者既不会把探索误读为无边界放行，也不会把治理误读为必须经过一个抽象中间节点。

这两个样例都说明：高质量审计不是找“作者哪里说错”，而是分开保留一条方向的价值、它尚未取得的关闭资格，以及最小可回开的修复位置。

## 把审计做成可复查的记录

日常记录只要足以让后来的人重走五问，不必把每处都写成案卷：

```text
位置与读者契约：
S前 → K → S后；被压低时的仍未排除近路：
关闭资格、重开条件、下游影响：
状态与最小回开：
```

只有主干关系、未证闭合关系或动用 Subagent 的关系，才扩展为下面的可复查记录。它不该只写“这一段不清楚”，而应让后来的人不看作者讨论史，也能重跑这次判断：

```text
读者契约与可见材料：
位置：句群／标题／顺序关系／[n]→[n+1] 边界
读者状态：S前 → S后
定向承载物，或转移缺口：
若 K 压低路线：仍未排除的替代路线 A1…An：
候选集、距离／并列规则与淘汰或不足状态：
文本缺口类型与选择的文本探针：
研究问题卡标识，或已消费的内容裁定卡版本：
最小反事实与下游影响：
选择的生成型探针及其冻结输入：
文本结论状态：被击败／未证闭合／价值未显露／授权未知／结构失败
击败锚点或缺失关系：
优先级：主干定向／关键分叉／枝叶
最小文本修复方向、依赖内容裁定的占位与仍未知事项：
```

多份独立报告不能以多数投票合并。在同一读者契约、相同输入、相同位置和相同缺失关系下独立指向同一问题时，它们可以形成较强的交叉印证；输入不同或问题不同的报告则应保留为不同证据。若报告分歧，先检查入口契约是否被遵守；重跑后仍分歧，才可能说明受众混杂、文本需要分路，或问题本身还没有足够材料收束。

## 这套方法仍然不能替代什么

它不能证明真实读者已经理解，也不能证明一套方法论、一个价值取舍或一项授权在现实中有效。模拟盲读只给出路径结构证据；内容关系的经验／因果、价值与授权问题必须交给[$research-content-judgment](../research-content-judgment/SKILL.md)，再由独立来源、真实主体和外部反馈承接。

它也暂时没有解决微小定向关系的累计漂移：单个“顺手略过”的句子可能不足以承重，大量同向省略却会慢慢把读者带偏。另一个未解问题是读者契约的粒度：契约太薄，任何转折都像承重；契约太厚，又会把作者想要的结论预装进审计前提。

因此，本文给出的不是一台能产出“文章正确”的机器，而是一条尽量短、却不跳过承重问题的文本审查路径：读者被带到哪里，文本是在打开、排序还是关路，文本凭什么声称可以这样安排，何时必须重开，这会不会带偏整篇。只有五问答不清或主干风险很高时，才做反事实、调用 Subagent 或提交研究问题卡。它不能证明自己是实现可重建、可质疑、可改走阅读路径的唯一充分方法；但任何替代方法也应能交代这些关系，而不把它们藏进顺滑的说服通道。

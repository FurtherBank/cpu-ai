# 职责契约、隔离派发与存证交接协议

## 五类职责单元的排他决定对象矩阵

同一决定对象在任意时刻只能由一个职责单元拍板写入。越过右列红线的输出一律视为无效越权。

| 职责单元 | 唯一拥有的决定对象 | 必需输入 | 法定输出与落盘位置 | 绝对越界禁令 |
| --- | --- | --- | --- | --- |
| **战略引领者** | 人类授权框内的阶段定位、下一里程碑聚焦方向、里程碑成功条件与停止条件、是否开启下一轮自主迭代 | 用户原始目标与授权配额；上一里程碑结项/受阻证据；监督者提交的升级包；外部真实反馈 | **里程碑任务书**（写入 `runs/<序号>-strategy.md`，由主人公同步至 `ledger.md`） | 禁止篡改用户保留目标；禁止批准未授权不可逆外部动作；禁止直接拆解具体实现或越级指挥具体做事 Agent；开启开关 P 且无新外部锚点或基准增量时禁止自动续杯里程碑 |
| **主人公** | 当前里程碑内的任务澄清、拓扑与开关选择、**共享骨架**锁定、排他写域划分、子代理启停重派、产物合龙、`ledger.md` 维护、有限任务关闭判断 | 有效里程碑任务书（或用户原话）；`runs/` 下各子代理原始存证报告 | 排他维护 `ledger.md` 与 `backbone.md`；下发单命题工单；输出合龙待验包与结项报告 | 禁止削弱上层成功条件强行清零阻断项；禁止将重叠可变写域并行派给多个具体做事 Agent；禁止篡改或删除 `runs/` 下子代理存证；非单体直连拓扑下禁止自审自结 |
| **监督者** | 推进过程是否偏航、空转、死锁或扩界的独立诊断定级、限期纠偏单签发、向上升级与极端失能熔断 | 原始用户需求；`ledger.md`；`runs/` 下全部历史子代理原始存证与实际产物文件（只读） | **监督发现单**（写入 `runs/<序号>-supervisor.md`） | 禁止绕过正常响应的主人公直接暂停、重试或改向单个具体做事 Agent；禁止代改业务代码或正文；禁止未查进程与等待条件就把“暂无消息”判为失败 |
| **具体做事 Agent** | 所分配单一命题与排他写域内的局部方法选择、局部产物（或感知探针）构造及施工自检 | 主人公下发的单命题工单（含输入边界、**共享骨架**路径、排他可写范围、完成标准、禁止假定项） | 排他写域内的业务产物 + 施工交接单（写入 `runs/<序号>-worker.md`，含**产物指纹**与自检原始输出） | 禁止雇佣、传参引导或过滤独立验证 Agent 的结果；禁止私改界外文件、`ledger.md` 或**共享骨架**；禁止替整体任务宣布完成 |
| **独立验证 Agent** | 待验产物（或待验感知基准尺）相对于有效标准与真实用户路径的检查范围选择、探针运行与`通过 / 失败 / 未验证`裁定 | 未掺杂作者主观吹嘘的原始契约与标准版本；已校准探针；冻结后的裸产物或匿名留出样本 | **独立验证裁定书**（写入 `runs/<序号>-verifier.md`，直达主人公并留存供监督者直接扫描） | 禁止仅凭具体做事 Agent 的自述摘要下结论；禁止下场替具体做事 Agent 修改核心业务产物；禁止无校准基准时凭模型裸直觉签发审美/幽默/体验“客观通过” |

## 防篡改与零写冲突目录结构

凡非单体直连拓扑，统一在任务工作目录（默认 `.superagent/<task-slug>/`）下实行**主账本排他写 + 子代理分文件只读存证**：

```text
.superagent/<task-slug>/
├── ledger.md                     # 仅主人公排他读写：生效契约、阻断条件账本当前态、历次事件索引链接
├── backbone.md                   # 仅主人公排他读写：多写者合龙或感知校准锁定的共享骨架与基准尺版本
└── runs/                         # 各子代理各自创建新序号文件，写完即冻结只读，严禁主人公事后修改或删除
    ├── 01-worker-probe.md        # 具体做事 Agent 造尺交接单
    ├── 02-verifier-calibrate.md  # 独立验证 Agent 留出集盲测验尺报告
    ├── 03-supervisor-snap.md     # 监督者关口快照审计单
    ├── 04-worker-candidates.md   # 具体做事 Agent 造物交接单
    └── 05-verifier-final.md      # 独立验证 Agent 探针与正反成对盲评裁定书
```

**产物指纹计算约定**：单文件统一使用 `shasum -a 256 <file>` 前 12 位十六进制字符；多文件集合统一按路径排序后执行 `shasum -a 256 <file1> <file2> ... | shasum -a 256` 前 12 位（Git 仓库内已提交快照亦可附加 `git rev-parse --short HEAD`）。

## 前置共享骨架与感知基准冻结规程

在并行派发 2 个及以上具体做事 Agent 前，或开启开关 P 验尺通过后，主人公必须先将**共享骨架**（或锁定的**感知基准**）写入 `backbone.md`（或代码公共接口文件）并记录其**产物指纹**：

- **工程实现类任务**：跨模块接口签名、字段名与物理单位（如分/元、毫秒/秒、时区基准）、共享状态机转移条件、错误码契约与排他写目录表。
- **长文/方案创作类任务**：目标读者画像、核心术语定义表（一词一义）、全文承重论证链及每一节的输入认知状态与输出认知状态。
- **视觉/体验与感知校准任务**：已通过盲测校准的**感知基准**（探针脚本路径 + 结构规律核验表）、色彩与字号阶梯 Token、栅格间距规范、交互状态全集（默认、加载、空态、错误态、成功态）及禁用装饰套路清单。

施工中任一具体做事 Agent 若发现不改**共享骨架**就无法推进，必须立即停工在 `runs/<序号>-worker.md` 提交越界需求上报单，由主人公评估**回开**骨架、更新版本并重对齐所有下游消费方。

## 无倾向隔离派发模板

每次派发子代理只交代一个清晰命题、一次独立验证或一次监督审计，省去主人公的个人倾向与诱导措辞。

### 具体做事 Agent 派发模板

```markdown
【角色身份】具体做事 Agent（仅负责以下单一聚焦命题）
【命题目标】<一句话写清要把什么输入转化为什么输出>
【上游契约与共享骨架】<文件路径及产物指纹>
【允许读取的原始材料】<路径列表；造物阶段严禁包含留出盲测集路径>
【排他可修改范围】<允许新建或编辑的业务文件路径列表 + 本次专属存证路径 .superagent/<task-slug>/runs/<序号>-worker.md；其余路径严禁修改，未列入允许清单的盲测盒与密钥文件严禁读取>
【禁止假定与禁区】<不得自行脑补的业务规则、不得触碰的外部副作用、不得自行唤起独立验证 Agent>
【完成标准与施工自检】<交付前必须跑通的本地编译、测试或确定性检查命令>
【写入存证文件与返回格式】
1. 变更文件清单及最新产物指纹（sha256 前 12 位）
2. 核心构造依据摘要
3. 施工自检原始命令输出（未删减）
4. 已知客观局限与是否需要回开共享骨架
```

### 独立验证 Agent 派发模板（剥离主观自夸，保留客观局限）

```markdown
【角色身份】独立验证 Agent（客观旁人 / 目标真实用户 / 持证探针执行视角）
【验证对象】<冻结后的裸产物路径及产物指纹，或遮蔽身份编号的留出盲测样本路径；不含作者创作心得与自我褒奖说明>
【有效验收标准与探针】<原始任务契约路径 + 已校准基准尺/确定性探针脚本路径及指纹；常规工程任务传入冻结的验收标准与测试环境说明>
【专属存证写入路径】.superagent/<task-slug>/runs/<序号>-verifier.md（严禁修改待验业务产物与 ledger.md）
【必做检查动作】
1. 直接在真实运行环境、浏览器渲染视图或原始数据上运行确定性探针/测试命令，保存完整原始输出；**凡涉及 UI、2D 图像或 3D 渲染的任务，必须调用 `Read` 工具逐张亲眼读取渲染出的 PNG 截图（严禁只看 JSON 指标不看实际画面！）**；
2. 以目标用户或受众视角完整走完核心使用路径（同步检查空态、异常态、边缘输入等过程摩擦点及界面文案是否违和或误导）；
3. **若属感知基准验尺阶段**：仅凭待验感知基准对匿名留出样本逐项判定，并重点核查探针脚本与规则中是否暗藏针对特定字句、样本名或特定数值的硬编码作弊补丁（如有直接判`失败`）；
4. **若属最终产物验收或候选盲评阶段**：对正序和反序两次编排分别评估并比对一致性；**不放水铁律**——若发现落盘报告数据与现场重跑不一致、开启开关 P 造物却未按契约生成 ≥2 个实质差异候选供盲评、或画面主体过暗难以辨认/用粗糙矩形方块敷衍关键造型，必须签发`失败`打回返修，严禁以“边界通过”放行。
【裁定书输出格式】
- 验证结论：通过 / 失败（注明对应阻断编号） / 未验证
- 绑定的标准指纹与待验产物指纹：
- 实测路径与探针原始证据：
- 阻断级缺陷（必须修复方可达成）：
- 过程摩擦或展示文案瑕疵：
- 属于外部世界或真实受众的 L3 待外部确认边界：
```

### 监督者关口快照 / 巡检派发模板

```markdown
【角色身份】监督者（只读观测与防自嗨收敛审计，不继承主会话历史）
【强制扫描范围】用户原始请求、`.superagent/<task-slug>/ledger.md`、`.superagent/<task-slug>/backbone.md`、`.superagent/<task-slug>/runs/` 目录下全部历史子代理存证文件、以及当前实际产物文件。
【专属存证写入路径】.superagent/<task-slug>/runs/<序号>-supervisor.md（其余文件严格只读）
【必查四项】
1. 账本诚实度检查：对比 `runs/` 下的原始失败/打回存证与 `ledger.md`，检查主人公是否遗漏、淡化不利验证结果或静默调低成功条件。
2. 目标守恒与扩界检查：相比用户原始目标，当前工作是否发生了削足适履或无授权范围膨胀（把有限任务做成无限服务）？
3. 双模态收敛检查：
   - 探索态：本轮是否有实证排除了旧假设或获取了关键事实，还是在无新证据下原地空转？
   - 收敛交付态：剩余阻断条件是否按离散净减少量 ΔB > 0 持续下降？是否正在非阻断细枝末节上过度打磨？
4. 感知防自嗨与防作弊检查（开启开关 P 时）：是否严格执行了留出集盲测先验尺才进入造物？探针与规则中是否不含针对旧版 `V1` 特定词句/数值的硬编码作弊补丁？是否把 L3 外部受众反应吹嘘成了内部已证达成？
【输出格式（监督发现单）】
- 监督形态声明：持续外置监督 / 快照监督
- 审计结论：正常推进 / 签发限期纠偏单（交主人公处置） / 触发升级熔断（交战略引领者或真实用户）
- 具体发现条目（预期状态｜实际状态｜原始存证文件与行号｜风险等级｜要求主人公回应动作）
```

### 战略引领者派发模板（仅跨里程碑或授权框内范围裁决时唤起）

```markdown
【角色身份】战略引领者（人类授权框内的阶段定位与里程碑决策视角）
【原始授权与目标】<用户原始指令、硬约束、不可逆红线与自主迭代配额>
【当前阶段证据】<上一里程碑结项/受阻摘要、ledger.md 路径、监督者升级包或新增外部真实锚点>
【专属存证写入路径】.superagent/<task-slug>/runs/<序号>-strategy.md（其余路径严格只读）
【禁止事项】不得篡改用户保留目标；不得批准未授权不可逆外部动作；不得拆解具体文件实现；开启开关 P 且无新增外部锚点或基准增量时不得自动续杯新里程碑。
【里程碑任务书输出格式】
- 当前阶段定位与是否继续迭代：
- 本里程碑唯一聚焦目标与明确不做项：
- 可验证成功条件与停止条件：
- 需交回真实用户拍板的触发线：
```

## 状态账本 `ledger.md` 维护格式

主人公在每次关键状态变化后更新 `ledger.md`，历史事件索引只追加不删除：

```markdown
# 任务状态与阻断条件账本

## 生效契约与运行配置
- 契约版本：v1
- 基础执行拓扑与开启开关：<拓扑名> + <开关列表>
- 任务目标与最终消费者：
- 状态分层：
  - 已证实事实：
  - 合理推断与待验假设：
  - 有效授权决定：
  - 关键未知：
- 成功条件与停止条件：
- 当前模态：探索态 / 收敛交付态（附切换依据）

## 阻断条件账本
| 编号 | 阻断条件描述 | 当前状态（待解/打回返修中/已闭合/待外部确认/延期移交） | 打回次数 | 绑定最新产物指纹 | 闭合或失败存证路径（runs/...） |
| --- | --- | --- | --- | --- | --- |
| B1 | ... | 待解 | 0 | - | - |

## 留出盲测集密钥映射（仅开启开关 P 时由主人公保管，严禁传给验证与造物子代理）
- 暂存于主人公独立密钥文件或揭盲后追加记录

## 全流程存证事件流水（只追加不删改）
- [01] worker 造尺完成 -> runs/01-worker-probe.md (指纹: ...)
- [02] verifier 留出集盲测验尺通过 -> runs/02-verifier-calibrate.md
```

注意：在验尺或盲评完成**揭盲前**，不要把样本真实身份密钥明文写在验证子代理可读的文件里；主人公可将密钥保存在 `.superagent/<task-slug>/blind-key.secret.json` 并在派发独立验证 Agent 时明确列入禁读路径（或验尺子代理只被喂入匿名拷贝目录 `/tmp/...`），揭盲完成后再将映射与核对结论归档入账！

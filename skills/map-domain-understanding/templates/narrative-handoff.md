# 认知叙事交接快照

```markdown
# 叙事交接：${batch_id} ${batch_title}

## 版本与范围
- 地图版本：
- fixture_lifecycle: draft # 只表示测试前的 fixture 生命周期，不预告测试结果；正式复制后仍保留
- 认知契约：
- 路线 ID：
- 本批节点：
- 已满足前置节点：

## 读者与任务
- 目标读者：
- 读者入口状态：
- 当前要解决的问题：
- 本批终态能力：

## 逐节点契约
### ${node_id}
- 当前缺口：
- 为什么此刻转向：
- 允许使用的主张及材料角色：
- 必须承载的推理桥：
- 更新后的判断与强度：
- 适用边界和条件分支：
- 不可越过的未知：
- 下一节点或回访条件：

## 停止与回开
- 本批停止条件：
- 禁行节点或主张：
- 新条件出现时回开位置：
```

叙事交接快照从四个真源生成，每个路线批次一份。不得在快照中反向修改节点、主张、边或路线；发现问题时回开对应真源。`fixture_lifecycle: draft` 不表示通过；通过结论、批次 ID 与内容哈希只记在独立测试报告。正式快照是报告中已通过 fixture 的逐字节副本，因此不在文件内增加可变的“当前发布状态”。

# 封口地图并交接叙事

## Input

二选一：

- 可交接/受限可交接分支：通过测试的四个真源、同版本 draft 叙事交接快照、独立测试报告、允许交接的节点/路线、下游契约和正文授权。
- 阻断封口分支：候选四真源与版本、失败报告、最早责任阶段、无法在当前授权内修复的证据及精确外部缺口。

## Goal

可交接分支封口一致版本，并把独立测试报告中按批次 ID 与内容哈希判定通过的 draft 快照逐字节复制为正式 `handoffs/*.md`；受限可交接只复制安全路线快照。快照内的 `fixture_lifecycle: draft` 不改写；正式性由 `handoffs/` 路径、测试报告匹配记录和同版本四真源的 sealed 状态共同表示。阻断分支只封口本次执行和问题化候选包，返回 candidate 版本、失败证据和恢复动作，不保留 handoff。

可交接/受限可交接分支在四个真源无悬空 ID、正式快照与已烟测 draft 内容一致、叙事交接快照不构成第二真源、写作 Skill 无需补判结构或真值、行为日志完整时完成。阻断分支在候选状态未冒充通过、`readyRoutes=[]`、`handoffPaths=[]`、精确恢复动作和日志一致时完成。

## Guidance

按路线中的单节点或前置闭合批次切片。使用 [叙事交接快照模板](../templates/narrative-handoff.md)，确认交接快照能直接取得：读者与任务、入口缺口、终态、为什么此刻转向、材料角色、推理桥、边界、条件分支、前后节点和回访信号。小于等于 10 个批次时全检；更大时至少检查首批、每类条件/受限/螺旋批次和一张随机普通批次。

下游若仍需决定节点是否存在、关系是否成立、主张是否可信或价值取舍由谁决定，交接失败，回到最早上游阶段；不允许写作者边写边补地图。

用户只要求地图时，到交接快照集结束。用户同时授权教材写作时，按前置闭合批次显式调用 `cognitive-narrative-writing`；大型教材不得一次把全图塞给一个写作者。

新材料到来后先进入主张账，再沿稳定 ID 反查节点、边、路线和交接批次。根级变化可扩大回开，局部变化不默认重写全图。

## Execution Mode

主控封口、组包和维护版本。可选显式调用写作 Skill；返回产物、`behaviorLogPath` 和材料性影响摘要。

封口前对照 [行为日志质量标准](../references/audit-quality-standards.md) 和 behavior-log/v1 校验日志结构、阶段覆盖、子 Skill 链和资源索引。

**Audit Hook**：更新「关键行为」「子 Skill 调用」「影响清单」「结果与验证」「资源索引」，随后封口父日志。

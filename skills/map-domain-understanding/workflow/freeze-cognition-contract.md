# 冻结认知契约

## Input

- 用户原始需求、领域对象、目标读者、使用任务。
- 明确范围、风险、权限、不可牺牲约束和决定权。
- 材料入口只作路径索引；本阶段不得按材料目录排节点。

## Goal

生成 `cognition-contract.md`，包含契约级体系范围、读者入口、使用任务、终态能力矩阵、约束、承重未知、条件分支和决定者。契约级体系范围只界定纳入/排除的对象、时间、场景和责任边界，不提前展开节点级内容目录。

当且仅当每项终态都有现实可观察任务与通过证据，契约级体系范围已封口，且改变地图主干的未知已分流时完成。禁止提前列章节、认知基座或节点级内容目录。

## Guidance

先问“读者读完后要解决什么现实问题”，再问“需要理解什么”。把“掌握 X”改写成：给定什么条件，能区分、解释、判断、行动或迁移什么，并说明何时不可使用。

角色不是先备知识证明。只有输入明确或可观察诊断支持的知识才写成可调用前提；其余标为待诊断。

若不同终态会改变契约级范围或路线主干，分别登记能力子集，不取平均。若只改变例子或讲解深度，保留同一能力。

异常处理：

- 无法设计观察任务：缩小目标或请求决定。
- 材料目录开始左右终态：隐藏目录，重新从使用任务定义能力。
- 风险、授权或优先级无人决定：记录影响和决定者，只推进不依赖它的局部路径。

## Execution Mode

主控连续执行，不委派。写完后对照 [认知契约闸门](../references/quality-gates-and-reopen.md#认知契约)；失败不进入材料处理。

**Audit Hook**：更新「依据与关键输入」「关键行为」「偏离、异常与未决事项」。

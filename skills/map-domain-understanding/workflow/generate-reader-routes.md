# 生成读者遍历路线

## Input

- 已封口的认知契约、节点和边。
- 已通过诊断、可视为完成的节点 ID 集合 `S`。
- 认知契约中已冻结的目标能力 ID 集合 `T`。
- 节点叙事门与权限边界。

## Goal

生成 `routes.md`：推荐主路线、必要替代入口、补前置、回访和停止条件。字段遵守 [产物契约](../references/artifact-contracts.md)。

当所有目标能力被覆盖或明确阻断，每条 usable 路线理解前置闭合，首批有可观察能力，横切约束及时出现时完成。

路线静态闸门通过后，主控按叙事交接模板为每条候选安全路线的每个路线批次各生成一份同版本 `.draft-handoffs/<route_id>-<batch_id>.md`。这些是阶段六叙事消费烟测的实际 fixture；测试前不得另写一份摘要代替。

## Guidance

采用“约束门控 + 效用批次 + 局部贪心”，不用加权评分：

1. 以各能力的 `pass_evidence` 生成尚未达成的 `T_remaining`；未验证先备知识先诊断，诊断只改变 `S`。
2. 对每个剩余能力，只把 `ability_refs.role=realizes` 的节点作为目标节点；`supports` 节点只能通过关系闭包进入。内容未放行、权限不足或范围不明时标 blocked。只有契约已存在较窄的独立能力 ID 才能改选，否则回开阶段一，不得现场降级终态。
3. 为每个候选目标回溯最小理解前置闭包，减去 `S`；删除仅有帮助的关系；在首次影响含义、权限、风险或责任前插入横切约束。
4. 词典序选择下一批：安全可达 → 立即形成可观察能力 → 新增理解前置较少 → 对剩余目标复用更多 → 跨主要变体更稳定。仍并列则保留等价入口，不继续精排。
5. 批内按理解前置局部排序；完成后把已验收节点加入 `S`，只有能力的通过证据成立时才从 `T_remaining` 移除，随后重算下一批。

经验诊断只改变 `S`；角色和任务只选择契约中既有的 `T` 子集；权限只改变可达性。入口和示例视角不复制节点，也不改写能力定义。补前置链只包含理解前置和首次生效约束。

只有伪循环已排除、反馈真实存在、读者必须先有不完整模型才能观察修正信号时启用螺旋。每轮包含薄模型、代表性案例/观测、指定维度修正，并预声明新增判断、撤销外推或新边界。没有认知增量就停止。

## Execution Mode

主控执行。路线不得修改 `system-map.md`。读者偏好、篇幅和示例只可用于等价路线的表现选择，不能覆盖理解前置和风险门。

**Audit Hook**：更新「关键行为」「影响清单」「结果与验证」「偏离、异常与未决事项」。

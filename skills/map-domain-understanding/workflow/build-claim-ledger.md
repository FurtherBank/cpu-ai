# 建立材料—主张账

## Input

- 已通过的 `cognition-contract.md`。
- 授权使用的材料入口和本轮版本/时间边界。
- 按需引用的研究、行业或组织规范路径。

## Goal

生成 `claim-ledger.md`。只收录会支撑节点、边、边界或分支的材料和承重主张；字段遵守 [产物契约](../references/artifact-contracts.md)。

当所有承重主张可回到来源，认识状态和叙事权限明确，重复与冲突未被抹平时完成。禁止建设与终态无关的全量摘录库。

## Guidance

以“这条材料将支撑哪个节点、关系或边界”为收录问题。回答不出的内容不进入主张账。

先确定认识状态，不看期望教材结论；再按当前任务与边界计算叙事权限。价值或授权项没有具名决定者与范围时阻断。`带条件允许` 必须记录随主张传播的条件；条件在节点或叙事交接快照中丢失时自动按阻断处理。

一句话混有事实、价值和建议时拆开。同名主张若对象、时间或条件不同，不合并；异名主张只有在操作含义和失效后果相同时才候选合并。

缺口分流：

- 需要新增事实材料或多源交叉验证：调查研究。
- 材料已有，但定义、关系、必要性、竞争模型或价值取舍未封口：内容裁定。
- 风险阈值、权限、优先级或组织规则：有决定权者。

材料量大时，一个抽取者只消费一个来源或同源材料簇。返回材料记录、主张记录、引用位置和未解析项；禁止跨来源合并真值。

## Execution Mode

主控维护总账、统一 ID、去重并确认叙事权限。单来源抽取可用纯 Task；调查研究或内容裁定必须显式调用相邻 Skill。

显式子 Skill 返回：`{交付物, behaviorLogPath, 材料性影响摘要}`。

**Audit Hook**：更新「关键行为」「子 Skill 调用」「影响清单」「偏离、异常与未决事项」。

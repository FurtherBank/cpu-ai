# 行为日志本地兼容协议

仅当 sibling `behavior-log-audit` 的契约或骨架不可读时使用；可读时必须使用原契约。

## 最小结构

日志仍写到 `SKILL.md` 规定路径，并按顺序包含：元数据、执行边界、依据与关键输入、关键行为、子 Skill 调用、偏离/异常/未决、结果与验证、影响清单、资源索引。

元数据至少记录规范标识 `behavior-log/local-fallback-v1`、执行 ID、Skill、状态、开始/完成时间、工作区、目标和 `auditDependencyMode=local-fallback`。关键行为按时间追加，不回写成事后完美叙事。

显式子 Skill 记录输入边界、产物、`behaviorLogPath` 和材料性影响摘要；纯 Task 只记父日志摘要。子日志路径不可访问时先请求可访问路径；仍不可访问且结果被地图消费时，审计闸门失败，只能阻断封口，不得伪造子日志。

封口前确认固定章节齐全、无执行中占位、地图版本和状态与返回值一致、所有写入与外部影响可追溯。连本协议也不可读或无法写日志时，不开始建图，使用 `SKILL.md` 定义的预建图阻断空制品返回，不进入七阶段。

# map-domain-understanding：行为日志可比对质量标准

## 结构完整性

- [ ] 日志位于 `.skill-logs/map-domain-understanding/yyyy-mm-dd/hhmm-*.md`
- [ ] 元数据包含规范版本、执行 ID、Skill、状态、时间、工作区和执行目标
- [ ] behavior-log/v1 固定章节齐全且顺序正确
- [ ] 封口后无执行中占位，终态与完成时间一致

## 阶段覆盖

| 阶段 | 日志须更新的章节 | 完成判据 |
| --- | --- | --- |
| 阶段一：冻结认知契约 | 依据与关键输入、关键行为、偏离/异常/未决 | 读者、终态、范围、约束和决定权可追溯 |
| 阶段二：建立材料—主张账 | 关键行为、子 Skill 调用、影响清单、偏离/异常/未决 | 材料边界、认识状态、分流和子日志可追溯 |
| 阶段三：反推认知节点 | 关键行为、影响清单、结果与验证 | 三路候选、删除反事实、节点闸门和移除理由可追溯 |
| 阶段四：封口体系关系 | 关键行为、子 Skill 调用、影响清单、结果与验证 | 边、基座、循环判断和隔离攻击可追溯 |
| 阶段五：生成读者遍历路线 | 关键行为、影响清单、结果与验证、偏离/异常/未决 | 约束门、效用批次、替代入口和阻断可追溯 |
| 阶段六：独立测试体系认知地图 | 关键行为、结果与验证、偏离/异常/未决 | 用例动作、预期结果、逐项证据、下一状态、失败回开与重测范围可追溯 |
| 阶段七：封口地图并交接叙事 | 关键行为、子 Skill 调用、影响清单、结果与验证、资源索引 | 可交接/受限/阻断分支与版本、交接快照、写作子链和遗留未知一致 |

## 子 Skill 链

- [ ] 每个显式相邻 Skill 在「子 Skill 调用」表登记
- [ ] `behaviorLogPath` 可访问，材料性影响已汇总
- [ ] 子日志路径不可访问时未被标为已验证；被消费的不可审计结果会阻断封口
- [ ] 纯 Task 只记录父日志摘要，未伪造子日志

## 影响闭包

- [ ] 地图包、交接快照、测试报告和任何外部动作均在影响清单可查
- [ ] 未修改的原始材料和外部系统在执行边界或影响清单有负向说明
- [ ] 顶层摘要覆盖地图终态、可用路线、阻断和遗留风险

## 与交付物对齐

- [ ] 资源索引链接四个真源、测试报告和叙事交接快照
- [ ] 日志不复制地图正文
- [ ] 返回的 `packagePath`、`mapVersion`（对应文件内 `map_version`）、`status`、`handoffPaths` 与实际制品一致
- [ ] 新材料回开记录能定位作废版本和保留范围

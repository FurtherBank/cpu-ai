# 质量闸门与回开

## 静态闸门

### 认知契约

- 每项终态能力有现实任务和通过证据。
- 读者角色、入口知识和权限没有互相替代。
- 范围、条件变体、约束、决定权和承重未知完整。
- 没有章节、材料目录或“核心知识”预判。

### 材料—主张账

- 所有被节点或边引用的主张存在且可回到材料锚点。
- 材料陈述、交叉支持、竞争中、未知和价值/授权决定可区分。
- 阻断主张未被 `ready` 节点消费。
- 重复来源未被当作独立证据；冲突未被编辑性合并。

### 节点

- 十个必填字段齐全、稳定 ID 唯一。
- `change/from_state/to_state` 能被读成一次认知变化。
- 每个节点有带 `realizes | supports` 角色的能力引用和删除后的具体损失；每项能力至少有一个合法 realizes 节点。
- `inputs` 标明材料角色。
- 没有只用“了解、熟悉、掌握”描述终态的主题节点。

### 关系

- 每条边有端点、类型、完整句语义、条件、失效后果、支持主张和位置状态。
- 没有未定义的“相关”边；理解前置不包含仅有帮助的关系。
- 认知基座引用受阻能力和承重边。
- 基座证明不引用尚未生成的路线产物。
- 循环经过节点拆分、术语消歧、时间尺度校正和删除反事实。
- 横切约束只有一个真源，范围变体未复制共同主张。

### 路线

- `usable` 路线理解前置闭合，`blocked` 路线写明第一个不可达点。
- 路线只对节点满足集做理解前置闭包运算；目标完成只按能力通过证据判断。
- `ability_targets` 均来自认知契约，路线未降级或改写终态。
- 横切约束早于首次受影响判断。
- 首个效用批次产生可观察能力。
- 替代入口含诊断、缺失前置和强制补前置点。
- 等价路线未使用无证据权重精排。
- 螺旋每轮有增量、边界、回访和停止条件。

### 封口与交接

- 四个真源版本一致，无悬空 ID。
- 四个真源的包 ID、地图版本与制品状态一致；sealed 版本未原地改写，旧 ID 未被另一语义复用。
- 派生视图没有第二人工真源。
- 叙事交接快照带版本与稳定 ID，只新增批次信息。
- 行为日志协议、Audit Hook、audit standards 和子 Skill 链完整。

## 独立测试协议

主控在派发前把每项用例实例化为：`case_id`、用例族、前提、fixture、逐步动作、预期结果、证据要求、通过判据、失败责任阶段和依赖回归用例。缺动作、预期结果或回开协议时，测试者拒绝执行。

| 用例族 | 必须执行的动作 | 通过判据与证据 |
| --- | --- | --- |
| 零基础顺读 | 从主路线入口逐节点核对前置，执行每批现实任务 | 无隐藏前置；首批和终态能力均有通过证据 |
| 按需跳读 | 选择替代入口或跳过点，计算缺失理解前置 | 强制补前置与横切约束未被绕过 |
| 条件迁移 | 改变一个已声明条件，沿主张、节点、边、路线追踪 | 范围外结论停止生效，只作废受影响集合 |
| 删除反事实 | 删除一个基座或承重边，重算终态结构支撑 | 实际损失与声明的失效后果一致 |
| 新材料回开 | 注入改变既有认识状态的测试材料并反查 | 能定位最早回开阶段与作废范围 |
| 叙事消费烟测 | 给模拟写作者由候选真源生成、同版本的 draft 叙事交接快照 | 写作者无需重判节点、关系、主张真值或决定权；阶段七正式快照与该 draft 内容一致 |

存在争议内容时加禁行测试，存在真实循环时加两轮增量测试。测试者只消费原始需求、四个候选真源、同版本 draft 叙事交接快照、本固定协议和已实例化用例清单，不消费设计过程或主控自评。

每项返回执行动作、预期、实际、结论、证据和最早应回开的阶段。叙事消费烟测另须为每份 fixture 返回 `route_id`、`batch_id`、路径、内容 SHA-256 与通过/失败；这些记录是阶段七允许复制的白名单。测试者不修改地图。

## 状态迁移

- 阶段一至五静态闸门通过后才能测试。
- 全部目标路线通过：进入可交接封口。
- 安全子集通过且与阻断部分隔离：进入受限可交接封口。
- 测试失败且能在当前授权内修复：回开最早责任阶段，不得交付。
- 缺口当前不能修复时，先判断是否存在通过全部相关测试且与受阻部分隔离的安全路线：存在则受限可交接；没有或无法证明隔离才进入阻断封口。

阻断封口只保留问题化候选包、证据与恢复动作；不生成叙事交接快照，不调用写作 Skill。

## 回开路由

- 入口、终态、范围、决定权：阶段一。
- 来源、主张、认识状态、叙事权限：阶段二。
- 节点粒度、入口、增量、叙事门：阶段三。
- 边、基座、横切、变体、循环：阶段四。
- 顺序、效用批次、入口、补前置、回访：阶段五。

回开阶段及其受影响下游版本作废；未被依赖传播命中的部分保留。修复后重跑静态闸门、失败用例及依赖它的回归用例。

## 完成标准

可交接要求全部目标路线通过相关必跑/条件测试；受限可交接要求安全子集通过全部相关测试及隔离测试。两者都要求 draft 叙事交接烟测无需下游补判、行为日志校验通过。没有安全路线时只允许以“阻断”交付问题化候选骨架，不得声称可进入教材写作。

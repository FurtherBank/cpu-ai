# 相邻 Skill 边界

## 与 cognitive-narrative-writing

本 Skill 决定领域中有哪些认知节点、节点为何必要、关系是否成立、内容能否放行、读者走哪条路线。`cognitive-narrative-writing` 只把已封口节点或批次写成可检查、可质疑、可迁移的理解路径。

写作 Skill 若仍需决定节点、关系、真值或价值取舍，交接失败，应回开本 Skill；不能边写边补地图。

## 与 cognitive-narrative-review

本 Skill 的独立地图测试验证地图是否可遍历；`cognitive-narrative-review` 验证已经成文的叙事是否带偏读者。地图通过不等于文章通过，文章问题也不一定要求改地图。

## 与 derive-cognitive-workflow

`derive-cognitive-workflow` 的节点是完成一项任务时执行者的认知状态转换，一次默认展开任务图的一层。本 Skill 的节点是读者理解某个领域时需要获得的认知变化，并需要同时形成全域结构和多条消费路线。

用户问“建图这项任务内部还要怎样展开”时，可另行使用前者；不要把角色、活动或工作流步骤写成领域认知节点。

## 与调查研究和内容裁定

- 缺少新增事实材料或需要跨渠道交叉验证：转调查研究。
- 材料已经存在，但定义、关系、必要性、竞争模型、价值取舍或授权边界未封口：转内容裁定或有决定权者。
- 本 Skill 只记录缺口、影响、所需输入和回填位置，不替相邻任务生成答案。

## 与单篇写作和资料索引

已有稳定小范围结构、只需写一篇文章时，直接使用写作 Skill。只需定位事实或材料时，使用检索/研究；不要为轻量任务建立完整体系地图。

# 派发模板

军团长在调用真正的子 Agent 前填入以下信息。这里的字段是当次运行输入，缺少时回查 task.md 或现有材料；不能用摘要偷偷替换原始约束。路径须在接收者环境可读，无法共享文件时内联对应内容。

```text
你的职责：角色名称。
角色模板：军团长填入可读的绝对路径，或直接内联对应模板正文；不得只写“当前包里的模板”。
用户原始任务：完整原话，或可读的原文路径与准确版本。
当前有效任务约定：task.md 的路径、内容指纹；与原文不同的合法变更及决定来源。
本次命题与完成条件：要回答/改变什么，哪些事实才算完成。
必要输入：产物、接口/依赖、已存在的检查与证据，附准确版本和适用范围。
允许行为：可读/可写/外部动作范围、预算、停止条件、需要上交决定的触发条件。
执行关系：向军团长返回；所需上游/下游及不允许重叠写入的范围。
回应与接替约定：预期回应时点或可观测进度信号、谁观察、未回应时向谁升级、已有授权内的替补；由军团长按任务实际预期填入。
返回：结论/产物、真实依据和自检、准确版本、已知问题/跨任务影响、仍需什么决定；显式调用其它 Skill 时给 behaviorLogPath 和材料性影响摘要。
```

独立战略、监督、验证与隔离执行用无历史继承上下文；记录真实工具参数，不把仅在主控里切换角色语气当成新 Agent。最终报告只给可复核依据和判断摘要，不要求内部推理全文。

# 推导环节指引：从范围与候选关系到内容裁定卡

本指引覆盖研究循环的全部推导动作：冻结研究对象、指称外展、证据收集、思辨判决、竞争模型推演、收敛裁定与停止。输入是内容问题包，输出是内容裁定卡（两者模板见入口文件 SKILL.md）。术语沿用入口文件的术语速览，首次遇到不明术语先回查速览。

## 从范围走到可研究关系

有些内容问题来自已有文档；有些则尚未形成，不能只从作者的现成结论倒推。后一种情形先完成轻量的研究入口。

### 写出范围陈述

范围不是领域标签，而是一组可被研究推翻或收窄的陈述：正在解释什么现象、服务什么任务、为何值得处理、当前不处理什么。它可包含暂定定位，但不能把它伪装成不可改写的事实。

### 铺开概念与现实图景

从对象构成、参与者、条件、时间、失败方式、替代机制和关系延展出发，找出概念与真实限制。只保留能够明确说明关系的连接；“似乎有关”只是待研究线索，不是结论。

### 有限地选出承重命题

从关系中选出少量会改变后续理解、行动或模型拓扑，且尚未被已有结论回答的命题。每条命题都写明它为何承重、影响什么、以及为什么值得消耗研究资源。每条入选命题后续各自冻结为一个独立的 `U`（即一个单元），各出一张裁定卡，不合并冻结。

这三步的产物是候选关系 `R`，不是答案。后续仍须让它接受真实信息、竞争模型与反例的约束。

## 冻结可反驳的研究对象

把被审关系写成：

```text
U = <D, R, Γ, F, O>

D：适用范围与对象层级
R：被审关系及其量词、强度与方向
Γ：独立于 R 的保护约束
F：现实材料账，其中区分已核验观察 `F+`、待检验断言／推断 `F?` 与仅供追溯的来源指针 `L`
O：需要保住的合法输出或能力
```

例如，“所有合法路径都必须经过节点 C”才是可研究的 `R`；“C 很重要”不是。

`Γ` 可以包含真实硬边界，例如明确的权限限制、不可接受后果、已经获得授权的约束，或由有决定权者作出的可追溯价值裁定。它不能把 `R` 换句话塞进去。例如被审关系是“所有工作必须先经过节点 C”，而 `Γ` 里若预先写进“必须先产出 C 所产出的那种结果”，这只是 `R` 换了说法，不含 C 的模型在研究开始前就被定义性排除了。

### 提取成功条件

冻结 `U` 时，须为 `R` 与 `O` 提取**成功条件**：这条判断若做成了它声称要做的事，现实会呈现哪些可观察或可推导的状态、不会出现什么。成功条件是两条通道共同的靶子：现实通道检查现实是否呈现它们，思辨通道检查它们能否从已承诺前提推出。

提取不出成功条件的判断进入**缺靶**状态——没有靶子可审：它当前无法被证伪，也不得被依赖；这是缺陷裁定，不是豁免。作者不在场时，研究者可代拟成功条件，代拟版必须留档并可被作者方否认，否认后按新版本重审。

### 建立输入准入账

研究者不能顺手把原文的前提、目标和偏好带进 `U`。先为 `R` 留下原始表述、来源、量词、方向和版本；再为 `D、Γ、F、O` 的每一项记录：

```text
来源与冻结时间：
对象范围与类型：已核验观察 `F+`／待检验断言或推断 `F?`／已授权硬约束／有权者已裁定的价值／作者待裁定价值／仅供追溯的来源指针 `L`
删除 R 后仍应保留的独立理由：
何种信息会使该项失效：
```

把 `R` 暂时删除后，若某一项不能由独立权源、观察或有权者已作出的价值裁定重新表述，它不能进入既定 `Γ` 或 `O`；应把该项改归入被审关系 `R` 或待查事实，或作为待裁定价值另行并列记录（不进入 `Γ`／`O`）。作者提出的价值即使已写进原文，仍是待裁定项。`F?` 和 `L` 也不能被模型默认采信：前者只能生成待验证前提与证据卡，后者只能帮助找到材料。能改变裁定状态的输入只有两类：`F+` 现实锚点，以及通过辩护测试的前提可追溯推导（见「思辨判决通道」）。

`D` 与 `R` 还须附**来源命题映射**：有原文时映射原文主张；没有原文时记录初始命题表述、其来源与“原文不适用”。无论来源如何，未限定的量词不得在研究开始时先行缩窄；任何缩窄都是待审的条件化结论，必须列出被排除的现实切片。范围、目标或输出在看见反例后改变时，必须作为新版本重新审查。

## 指称外展：补全现实材料账

能给一个判断定罪的事实，常常不在判断的文本里，而在判断触及的事物的未被调用属性里。判断使用一个实体时只把它**角色化**——只调用它的一两个属性；而现实中的实体是全量的，未被调用的属性照样起作用。说白了就是：判断说“用户会点这个按钮”时只用了用户“会点击”这一面，但用户还有耐心上限、来源分布、流失习惯，判断的死因常藏在这些没被点名的属性里。注意力跟着判断文本走时，检索在拓扑上到不了这些事实；这类失败是检索失败，不是推理失败，靠“更认真地想”解决不了，要靠固定协议。

在证据收集与思辨论证开始前，按三步为 `F` 账供弹：

1. **指称清单**：列出判断触及的一切存在物——显式提到的实体、动作、人群、资源，加上隐式指称：谁执行、谁受影响、依赖什么工具与渠道、发生在什么时间窗、经过什么媒介、谁会对结果做出反应。隐式指称漏项是头号失败方式，须按这份追问词表逐条过，不靠临场想到。
2. **全量档案盲外展**：对每个承重指称，由不看判断本身的执行者按固定算子展开百科级基本事实：正常行为与基率、容量与极限、生命周期与衰减、失败方式、激励与应激反应（有能动性的实体此项最常被低估）、历史上被尝试过什么及结果、与其他指称交互的二阶效应。不看判断是防污染的关键：带着判断去找事实，只会检回确认方向的材料。外展产物一律先记 `F?`，经查证才升 `F+`。
3. **相交回判**：把外展档案对着成功条件相交：是否有事实堵住机制某一步、改变隐含基率、突破容量、引入会反制的行动者。只有触到成功条件或机制步骤的事实留入 `F` 账，其余丢弃——这一步是防淹没的过滤器。

预算规则：外展宽而浅，不做深研究；只对承重指称展开——机制上的单点、研究者最不熟悉的实体、有能动性的实体、被判断默认为恒定或被动的实体。另在判断整体层面固定加一个**参照类算子**：这一类判断或计划，历史上的成功率与典型死法是什么。

指称清单之外的存在物，本协议仍到不了；这是诚实残余，只能由现实运行兜住。

## 用真实信息提出双向问题

没有成熟最佳实践，不等于没有可研究的现实。不要搜索“谁的做法最流行”，而要从同一个 `U` 同时提出两组结论盲问题：

- **必要性问题**：哪项真实机制、硬约束、权源、资源限制、对象行为或失败记录，使 `R` 非存在不可？
- **可替代性问题**：在什么真实条件下，目标 `O` 可以由不含 `R` 的路径实现，或至少不与已知事实冲突？

优先取贴近对象的一手材料：实际规则与授权记录、运行或行为记录、真实失败事件、资源和时间限制、利益相关者的法定权能、对象可观察的机制。案例、论文、惯例和专家说法可以进入，但必须说明它究竟限制或支持哪个模型；多个转述同一事件不算多条独立证据。

研究至少覆盖普通切片、边界切片和最不利于原关系的切片。这里的**现实切片**是“对象类型 × 条件 × 时间或资源组合”的一个可运行情境，例如“新用户 × 信息不足 × 两天内必须决策”。真实信息的作用是淘汰或收窄模型，不是替原结论增添几个故事。

### 为每条现实锚点留下证据卡

```text
观察到什么；来源与收集条件；范围与可信度：
它触及模型的哪段机制：
各模型在此本应呈现什么不同结果：
实际结果、替代解释与尚未取得的反向材料：
```

只有预先写明、在相关范围内可观察、且材料质量足以区分的预期差异，才能改变模型状态。模型作不出可区分预期、或材料不足以区分时，这条锚点只能登记为背景或未知，不能用来宣布模型被击败或暂保留。价值判断和授权意见不能伪装成 `F`。在看见某模型或裁定草案后才挑出的材料，要标为**事后材料**；它可以触发回开或提出新证据卡，但除非按独立收集或预先说明的选择规则复现，不能单独维持或改变裁定状态。

## 思辨判决通道

思辨通道让定罪可以发生在现实验证之前，但合法弹药只有三种来源：被审判断自身的承诺（声明的目标、范围、宣称的机制）、双方已接受的既有事实（含已升为 `F+` 的外展产物），以及逻辑与数学。此外的似真性、类比和“感觉不对”，只能立存疑卡，不能定罪。

流程分三段：

1. **怀疑**：任何来源都可提出怀疑，登记为**存疑卡**：怀疑什么、论证走到哪、缺哪条前提、什么信息能闭合。同一判断累积多张独立存疑卡时升级优先级。
2. **论证**：把怀疑写成带编号前提的推导。每一步要么引用一条已承诺前提并标注来源类型（对方承诺／既有事实／逻辑步），要么是演绎或定义步；混入无法归类的似真步，整条推导无效。被打败的必须是判断的最善意重构版：承诺须可引用、可归属，不得用稻草前提凑定罪。
3. **辩护测试**：推导成立后，为被审判断辩护的仅有出路是 (a) 放弃一条已声明承诺、(b) 补一条本身需要经验支持的新前提、(c) 指出推导缺口。(a)(c) 都给不出、只剩 (b) 时，判决降档为“条件于前提 P 待定”；(a)(b)(c) 全都给不出时，定罪成立。

辩护搜索不得由定罪推导的提出者兼任：提出者的搜索方向已被自己的结论锚定，“辩方给不出”会退化成“起诉方宣布对方无话可说”。高承重定罪的辩护交给新鲜上下文的独立辩护人（见「用独立 Subagent 发现模型被顺手保留的问题」一节的角色表）；辩护人交回“无出路”报告之前，定罪不生效。低承重定罪至少换一次新鲜上下文再执行辩护搜索——单人执行时即清空工作上下文，只带 `U`、最善意重构与推导全文重新开始一次辩护搜索。高低承重的判定标准见入口文件术语速览「承重」条。

### 判决方向上限

凡在已承诺前提集内封闭的问题，思辨通道有全权判决；答案依赖前提集之外事实的，它无权判决，只能输出**剩余经验问题**——把“整个判断要不要拿去现实测”压缩成“只需查这一个分布或这一条事实”。由此思辨通道可以定罪（达不到成功条件）、收窄范围、判相对更优；对“判断在现实中会成功”，至多给出“经受住审查、暂存活”，加冕永远要现实通道。

### 构造性定罪与更优替代

定罪不得只断言结果不行，必须定位到判断的哪段机制在哪个条件下让成功条件落空。失败机制一旦定位，更优替代的构造面自动显形，其“更优”证明可复用定罪推导。

提出可证明的**更优替代**是本方法的正式交付之一。思辨上可证明的“更优”限两种形态：

- **支配**：同一成功条件与同一 `Γ` 下，替代判断在所有相关切片不劣于原判断、至少一处严格更优；
- **最小修复**：条件化收窄或局部替换后，可证明不丢失原判断已交付的任何东西，且堵住了已定罪的机制。

两个判断在不同切片各有胜负、优劣取决于切片出现频率时，思辨无权裁决，输出剩余经验问题；以价值权重改写胜负的，交回决定者。

## 生成并推演保约束竞争模型

不要要求研究者或 AI 对原结论表态。生成 `M0、Mc` 的角色可见冻结的 `U`；生成 `M−` 的角色只可见 `D、Γ、O`、待解释现象与 `R` 的**禁止复现规格**——只告知不得复现哪条关系及其量词、方向、范围的最小说明——不看原文叙述、作者偏好或原模型优劣说明。三者都结论盲地生成可运行模型。

| 模型 | 要做什么 |
| --- | --- |
| `M0` | 保留原关系，写清工作方式和会在哪些事实下失败。 |
| `M−` | 删除或替换被审节点／关系，仍须守住 `Γ` 与 `O`。 |
| `Mc` | 将全局关系收窄为条件门、局部关系、任务记录或另一种机制。 |

每个模型都必须写出输入、状态变化、谁能行动、可产生什么、不能产生什么、何处退出或回流，以及会被哪条真实信息击败。只说“还可以换一种做法”不算竞争模型。

高承重关系中，生成 `M−` 的人不应知道作者偏好或原模型的优劣描述；另一个独立视角负责攻击模型。这样减少的是推理同源，材料来源是否独立仍须另行记录。

将 `M0、M−、Mc` 放进同一现实切片，依次检查：

- 模型是否真的守住 `Γ`，还是静默放弃了必须保住的目标？
- 扰动一条权源、资源、信息或对象条件后，输出、合法性和回开位置怎样变化？
- 一条现实锚点支持的是模型哪一段，而非只让它听起来合理？
- 是否已有保约束、可运行、且与现实锚点相容的反例？

没有 `F+` 输入时，切片推演只是心智模拟，必须服从思辨通道的纪律：宣称某模型在某切片失败，该失败须可从模型自己写明的机制与已接受前提推出，并落成带编号前提的推导；仅由“听起来会失败”支撑的失败宣告，不改变任何模型的状态。

## 用独立 Subagent 发现模型被顺手保留的问题

高承重关系不应只由提出原模型的人自己寻找反例。可以让 Subagent 生成和攻击竞争模型，但它们的职责是制造可检查的差异，不是替代现实证据、价值决定者或权源。

先冻结 `U`、输入准入账、已取得的证据卡和本轮预算；再按一个未闭合风险选最少的角色，而不是让多个代理重复说“有道理”。

| 独立角色 | 可见输入 | 只交回什么 | 不可作出的结论 |
| --- | --- | --- | --- |
| 保约束删除者 | `D、Γ、O`、待解释现象与 `R` 的禁止复现规格；不看原文叙述、作者偏好和原模型优劣说明 | `M−`：删除或替换 `R` 后的可运行机制、它如何未复现 `R`、会失败的切片和待验证前提 | “原模型错误”或任何未经证据卡支持的事实。 |
| 约束渗漏审计者 | `U`、输入准入账与 `M−` | 哪一项 `Γ` 或 `O` 实际只是把 `R` 换名带回，或哪项被替代模型静默放弃 | 哪种价值应被选定。 |
| 反例攻击者 | 并列模型、证据卡、覆盖切片；不看作者结论 | 每个模型最脆弱的机制、还未覆盖的现实切片、能区分模型的下一条信息 | 把“暂未找到反例”写成“已经证明必要”。 |
| 证据区分审计者 | 证据卡和模型预期，不看推荐结论 | 该材料是否真能区分模型、来源是否独立、替代解释是否仍开着 | 以转述数量代替独立证据。 |
| 辩护人 | `U`、被审判断的最善意重构、定罪推导全文；不看推导提出者的倾向性评论 | 逐条尝试辩护出路：可放弃的承诺、可补的新前提、推导缺口，或“无出路”报告 | 以修辞否定推导；宣布定罪成立或维持原判断。 |

单人或无法派发独立角色时，不得声称已满足盲化。按可用手段降级：分次执行并在两次之间清空工作上下文、先写 `M−` 再看原文叙述，并在产出中记录「未隔离」及其影响；此状态下高承重关系最多给出存疑卡与暂定状态，不得给出定罪或更优替代的终局裁定。

各代理使用新鲜上下文，不互相看报告；主控最后按同一 `U` 整合。相同的约束渗漏或未覆盖切片被独立指出，是交叉印证；不同模型或不同切片是应并列保留的问题，不以多数投票消除。若输入不一致、证据卡缺失或代理越过可见材料补造事实，报告只记为“输入或执行无效”，不能参与裁定。

一份可消费的 Subagent 报告至少写明：`U` 的版本、可见与不可见材料、模型或证据卡位置、发现的精确差异、受影响的约束或现实切片、仍需何种现实信息，以及它不评估什么。这样，Subagent 帮助发现“原关系被措辞顺手保留”“反例只是假替代”“证据无法区分模型”等问题，却不会把语言流畅误写成内容结论。

## 收敛为可消费的内容裁定

比较的标准不是哪个模型最像原文、最容易画图或最容易写成 SOP，而是哪个模型在相同的保护约束、现实锚点和输出要求下先失败。

| 裁定状态 | 当前可作出的结论 |
| --- | --- |
| 缺靶 | 提取不出成功条件；判断当前不承担解释或行动职责，不得被依赖，须先补成功条件才能进入任一通道。 |
| 定罪 | 前提可追溯推导通过辩护测试，证明判断达不到自身成功条件；须附失败机制定位。 |
| 更优替代 | 存在经证明的支配或最小修复替代；原判断按被堵住的机制退场或收窄。 |
| 撤销全局必要性 | 存在保约束且可运行的反例模型，足以击败“所有路径必经”；局部功能仍待判断。 |
| 删除／拆解 | 已撤销全局必要性，且原节点的每项独立功能都有有效承接，节点不再有独有功能。 |
| 合并／迁移 | 功能可由已有节点、具体关系或任务记录承接，并已写清触发、责任和验证。 |
| 条件化 | 关系只在可事先说明的特定范围内有独有作用；写成条件门，不保留伪全局节点。 |
| 暂保留 | 已识别的竞争模型被可追溯的约束、合格推导或真实材料击败；只能说当前范围内尚未被替代。 |
| 未知／冲突 | 关键事实、权源、机制或价值裁定缺失或冲突；保留分支并规定未知期间的行动边界。 |
| 交回决定者 | 模型差异最终落在价值权重或决定权归属，而非可由研究裁决的事实。 |

同一单元可同时携带多个状态（如「定罪＋更优替代」「撤销全局必要性＋条件化」）。缺靶与准入不足优先于其它一切状态：未补齐前不得给出任何其它裁定。状态间冲突时取更保守者——更保守指允许下游依赖更少、行动边界更窄的那个状态；拿不准谁更保守时，降为未知／冲突并保留分支。

单个合格的 `M−` 足以撤销全局必要性，却不能单独证明节点在所有局部情境都无价值。若拟删除、合并或迁移节点，还要完成**功能覆盖表**：

```text
原节点承接的义务／能力：
触发条件、行动者与权源：
迁移后的接收关系：
可观察的功能验收标准：
在相关现实切片中产生原保护效果的证据：
失败时的回开点：
```

字段、文档或责任名存在，不等于迁移已经有效。未完成效果验证时，状态只能是暂迁移或未知；任一功能未覆盖，就只能条件化、暂保留或标为未知。

这里的**回开**，指新证据、约束或行动结果出现后，明确回到哪一版 `U`、哪张证据卡或哪项功能覆盖重新审查；不是泛泛地说“以后再看”。

回开触发不得只写在裁定卡里等待被想起：卡片是被动文档，没有观察者的触发不会自行生效。触发必须挂接到有自然流量的位置——最低要求是**消费时核验**：任何下游消费裁定卡前，先核对卡上的回开触发是否已经出现；已出现的，先回开重审，不得直接消费。条件允许时，再把触发绑定到该事实变化时必然被触碰的制品或流程入口。

### 未知与行动边界

裁定卡若包含未知、冲突或待决定项，必须写清：未知期间允许什么行动、由谁负责、需要什么证据才能回开。无法证明安全的行动只能做可逆探索；涉及权限、受保护对象或不可逆后果时，默认不执行。

## 停止、版本与回开

停止不是“已经想不出更多说法”。先按影响、不可逆性和可获得资源冻结研究预算，并写清必须覆盖的模型族、现实切片及选择理由；高风险关系还须经过独立攻击者。

满足以下任一状态即可结束本轮：

- 每种已识别的竞争模型都已在相关现实切片中运行，并有明确的事实或约束失败点；
- 已出现保约束反例，足以撤销全局必要性；若拟删除、合并或迁移，仍须继续完成功能覆盖及效果验证；
- 承重存疑卡都已走完论证，得到定罪、降档或明确未闭合的登记，剩余经验问题已压缩到最小并留档；
- 在已声明覆盖范围内，新的对抗性探索不再产生会改变状态的新约束、新模型族或新切片；
- 仍会改变结论的关键事实拿不到，因而状态应明确为未知或待裁定。

交接时记录覆盖范围、未测模型族、剩余暴露和回开触发。若资源不足以支持实际决定，应交回决定者，不能把搜索耗尽伪装成充分性。新的事实一旦改变 `D、Γ` 或 `O`，应回开研究对象。

裁定收敛并按模板写成内容裁定卡后，本环节结束。消费者是人类用户时，不要把裁定卡直接作为最终回复，进入交付转换环节（见 [delivery-narrative.md](delivery-narrative.md)）。

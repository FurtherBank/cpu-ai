# 研究性内容判断：从真实约束到竞争模型

> 当没有成熟最佳实践可以套用时，不是靠把原方案讲得更顺来决定内容，而是让它与保留关键约束的竞争模型一起接受真实信息、前提可追溯的论证、反例和可回开的检验。

这份方法审查的是内容模型本身：定义、分类、节点、关系、因果、必要性、价值取舍与授权边界，应当在什么范围内以什么强度成立。它可以用于研究议题、需求、方案、架构、流程、制度规则或方法论；不依赖文章、读者路径或任何特定体裁。

它不判断材料是否好读，也不以“模型完整”“惯例常见”“作者很有把握”为内容证据。表达是否让读者正确取得结果，应由相应体裁的审查另行处理。

这里的**保约束竞争模型**，指保留命题真正要守住的目标、硬边界、已知事实和权能限制，但允许删除、合并、替换或局部化原关系，再比较各模型能否在同一现实切片中合法运行。

说白了：不是给原图补例外，而是拿掉被怀疑的部分，检查真正重要的东西是否仍能被守住。

裁定状态只能被两条通道改变。**现实通道**：已核验观察 `F+`。**思辨通道**：**前提可追溯推导**（见推导环节指引「思辨判决通道」）——论证的每一步力量都来自被审判断自身的承诺、双方已接受的既有事实或逻辑演绎，而不是来自讲得顺。说白了就是：用对方自己承诺的目标和前提，证明它做不到它说要做的事。设思辨通道的理由是成本——很多判断在接触现实之前就能被便宜地定罪。两条通道判决权限不对称：思辨只能定罪、收窄或判相对更优，不能宣布判断在现实中成立。

## 两个环节与必读指引

本方法分两个环节，进入某环节前完整读取对应指引：

- [judgment-derivation.md](references/judgment-derivation.md)：**推导环节**——从范围与候选关系走到内容裁定卡：冻结研究对象、指称外展、证据卡、思辨判决、竞争模型推演、收敛裁定与停止。
- [delivery-narrative.md](references/delivery-narrative.md)：**交付转换环节**——消费者是人类用户时，把裁定卡与分析过程整理成「修改哪里／问题解释／推导过程」的三层交付叙事。

两环节的接口是内容裁定卡：它是推导环节的唯一权威输出，也是交付转换环节的对照基线。三层交付叙事只是裁定卡的消费视图，不得新增结论、提高强度或丢失条件；交付时暴露的内容级问题一律写成缺口卡退回推导环节。

## 术语速览

| 术语 | 一句话说明 |
| --- | --- |
| 保约束竞争模型 | 守住原命题真正要守的目标与硬边界，但允许删改原关系的替代模型。 |
| 成功条件 | 判断若真完成了它的工作，现实中可观察到什么、不可出现什么；提取不出即进入「缺靶」缺陷态。 |
| 缺靶 | 提取不出成功条件、没有靶子可审的缺陷状态；判断无法被证伪也不得被依赖，不是豁免。 |
| 前提可追溯推导 | 每一步要么引用已承诺前提、要么是演绎步的论证；思辨通道唯一合法的定罪形式。 |
| 辩护测试 | 定罪标准：辩方既指不出推导缺口、又不愿放弃已声明承诺、也补不出新前提时，定罪成立；只能补一条本身待验证的新前提时，降档为条件待定。 |
| 存疑卡 | 已提出但尚未闭合的怀疑：怀疑什么、论证走到哪、缺哪条前提、什么信息能闭合。 |
| 剩余经验问题 | 思辨无权裁决时输出的最小外部待查问题；把「整个判断拿去现实测」压缩成「只查这一个分布或这一条事实」。 |
| 判决方向上限 | 思辨通道只能定罪、收窄、判相对更优；「在现实中成立」只能由现实通道加冕。 |
| 指称外展 | 先列出判断触及的所有事物；再抛开判断本身，把其中承重事物的基本事实各查一轮；最后拿这些事实对照成功条件筛选入账。 |
| 角色化 | 判断使用实体时只调用其一两个属性；能定罪的事实常藏在被裁掉的其余属性里。 |
| 更优替代 | 在同一目标与约束下被证明支配原判断、或为其定罪部位最小修复的替代判断。 |
| 现实切片 | 「对象类型 × 条件 × 时间或资源组合」的一个可运行情境。 |
| 回开 | 新信息出现后，明确回到哪一版对象、哪张证据卡重新审查；不是泛泛「以后再看」。 |
| 单元 | 一次裁定的最小对象：一个冻结的 `U`。多条承重命题各自冻结为独立单元、各出一张裁定卡。 |
| 输入准入账 | 冻结 `U` 时为 `D、Γ、F、O` 每一项登记来源、类型与失效条件的清单；防止原文的前提和偏好被顺手带进研究对象。 |
| 承重 | 一个判断被多少下游理解、行动或模型拓扑依赖。命中「启动完整研究循环」的自动触发信号、或结论将支撑不可逆行动／多个下游依赖的，按高承重处理。 |
| 三层交付叙事 | 面向人类的固定交付格式：修改哪里→问题解释→推导过程，各层对一个消费深度自足。 |
| 可交付结论集 | 交付转换前从分析上下文拣选出的封口清单：可以说的话及各自强度、条件、未知；交付各步只准消费它。 |
| 缺口卡 | 交付转换中暴露内容级问题时的退货单：缺什么、在哪一步暴露、需补什么；交付层无权自行补内容。 |

## 这份方法处理什么，不处理什么

研究性内容判断处理的是会改变后续理解、行动或模型拓扑的关系级主张，例如：

- 一个概念边界是否应这样划分；
- 一个节点是否有不可替代的功能，还是应删除、合并或迁移；
- 一条关系是必要、充分、条件性还是只有相关性；
- 一项事实能支持到什么强度；
- 一项建议依赖的价值取舍是否已经显露；
- 谁在什么范围内有权决定或执行。

它不替代领域事实核验、有权者的价值决定、法律或组织授权程序，也不处理低风险的措辞编辑。遇到不可逆行动、受保护对象或权限问题，未知状态不自动允许执行。

## 什么时候启动完整研究循环

出现以下信号时，考虑把对象送入完整循环（是否启动按本节末尾的规则判定）：

- 主张含有“所有、只有、必须、必经、唯一、充分、必然”等全局或排他强度；
- 一个定义、节点、关系或分类被多个下游判断共同依赖；
- 改变它会改变概念定位、行动边界、价值取舍、授权理解或后续研究路线；
- 现有论据只是“这很顺”“这是常见做法”“体系闭环了”，没有独立现实依据；
- 关系的适用范围、停止条件、最近替代或资格依据答不清。

全局或排他关系自动触发。其余信号在影响多个下游依赖、不可逆行动或授权边界时触发；启动理由必须留档。

完整循环的推进顺序：冻结研究对象（含成功条件与输入准入账）→ 指称外展 → 双向问题与证据卡 → 思辨判决 → 竞争模型推演 →（按需）独立 Subagent → 收敛裁定 → 停止与回开 →（消费者是人类时）交付转换。深度可按预算裁剪；冻结与成功条件不可跳过。

## 输入：内容问题包

这份方法可以直接从范围与候选关系启动。来自文档审查、运行事故、需求分歧、设计评审或研究议题的输入，都先转译为同一种**内容问题包**：

```text
问题标识与待解释现象：
候选关系 R：主体、关系、量词／强度：
原始范围 D 与对象层级：
保护约束及其权源：
待查事实与已有材料：
需要保住的输出 O 与成功条件（提取不出时如实标注）：
优先级理由：影响、不可逆性、依赖面或授权风险：
已知替代关系与反例：
来源指针（可选，只供追溯，不构成证据）：
```

输入不全时，结果是“准入不足／待补材料”，不能通过补写假设把问题伪装成可裁定对象。

## 权威输出：内容裁定卡

本方法的唯一权威输出是**内容裁定卡**：

```text
单元与 U 版本：
裁定状态与当前可主张的关系、范围：
处置操作（删除／合并／迁移／条件化等，见推导环节指引裁定状态表）及其功能覆盖状态：
现实锚点、竞争模型、反例与未覆盖切片：
思辨记录：定罪推导、辩护测试结果、存疑卡与剩余经验问题：
价值或授权的责任归属：
未知期间允许的行动、责任人和禁止事项：
回开触发（含挂接位置）、版本与证据缺口：
```

上游来源可以解释为什么优先研究，却不能自动成为事实、硬约束或价值裁定。任何下游——包括本方法的交付转换环节，以及外部的体裁审查（如 cognitive-narrative-writing 的读者路径审查）——都只能消费这张裁定卡，不应自行把内容问题改写成内容结论。

## 边界

这份方法不能自动产出真理，也不能保证已经发现所有竞争模型。它的价值是让“还没有最佳实践”不再等同于“只能依赖原作者”；把当前结论降为带范围、真实锚点、反例、未知和回开条件的暂定模型。思辨通道的判决以已承诺前提集为界：前提集之内它有全权，前提集之外的世界仍须由现实通道与实际运行承接。领域事实、真实权源、实际用户反馈和不可通约的价值取舍，仍须由相应的现实程序承接。

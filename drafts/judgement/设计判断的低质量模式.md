# 设计判断的低质量模式

本文接在[《低质量判断的模式》](./低质量判断的模式.md)后面，只谈一类具体工作：创造性工作流里的**设计**。设计定义以工作区 `⭐️ cognition/创造性工作流/` 下的《设计》和《创造性工作的最基本模型》为准，不是口语里的「做设计」（画界面、想点子、把方案画出来）。

通用目录盯的是「接下来怎么想」被花过头。设计判断花的不是思维权，是下游对某个产物域能动手的那一档权利。

命中某个名字不算诊断。要用的话，得能指出：压那句话时买到的是哪一档行动权、后文或交接做成的是哪一档、这两档不是同一档。

---

## 设计判断压的是什么

设计接收已经承诺的方向与研究给出的现实边界，回答：产物为了服务这个方向，哪些可能性必须固定，哪些能在条件内变化，哪些可委托，哪些应延后，以及哪些仍无权决定。

一次设计判断压的是：**某个产物决策域应落入哪种行动权，以及这档行动权必须带着什么载荷**（不变量、可选空间、参数域、委托范围、延后条件，或把「未覆盖」显式暴露出来）。

它买到的权利是：让规划、实现、验证按这一档来消费这个域。它不买到重选方向、宣布事实或机制、为了好做而改产物语义、把未覆盖当成自由、把候选草图当成已经生效的授权。

输出不是实施蓝图，而是产物可能性授权契约。六个决策域状态的区别是行动权，不是措辞：

| 状态 | 下游权限 |
| --- | --- |
| 已指定 | 只能落实并验证，不得改选 |
| 受约束开放 | 可探索并选择合格解 |
| 参数化 | 仅能在定义域内配置 |
| 委托 | 被委托者在范围内决定 |
| 有意延后 | 不得把延后伪装为已决定 |
| 未覆盖 | 无权推断、填补或静默决定；未覆盖不等于自由 |

和三个近邻的岔路口不在措辞：

- 只改自己怎么想、不改授权契约，是发生在设计现场的通用判断，不是设计判断。
- 接受这句会重选未来位置或价值归属，应回开方向承诺，不是设计。
- 换一种做法不改变体验、可追溯性、隐私或验收对象，只改依赖和顺序，是规划，不是设计。

## 种的规则：可能性授权超额

通用「改写权超额」还是属。设计这一层的种叫**可能性授权超额**。说白了：那句话只买到「这个域下游能做什么」的某一档，交出去的契约或后文却按更大的一档让人动手。

观测落点因此换了。通用目录看后文有没有「只能 / 因此排除 / 不必再查」。设计现场可以完全没有这些词，却已经把「未覆盖」花成「实现时按惯例补」，或把一张比较草图送进排期。

六个状态是**状态赋错的观测格**，不是分类轴。写成「已指定的错 / 开放的错」会把另外几个家族挤掉。「未覆盖不等于自由」是最锋利的原型实例，单独升格成一条，就没有理由不把「延后当已决定」也各升一条。

## 低质量模式

### 把这个域的行动权写成了另一档

- **未覆盖被花成自由**：只标了「本次未覆盖」，后文却按「实现可以自己定」来用。
- **延后被花成已决定**：只买到「先挂起，不得伪装成已定」，后文却按已经选定往下做。
- **受约束开放被花成已指定**：只买到「在硬约束里选合格解」，后文却把其中一个解锁死。
- **已指定被花成可改选**：只买到「下游只能落实」，后文却按还可以改选来用。
- **空授权**：口头写着开放，手里没有硬约束和验收。

### 盖设计章，花方向、研究或规划的钱

- **局部选择被写成方向**：在既定方向里治理产物可能性，却拿去重选未来位置或价值归属。
- **设计正文补事实或机制**：无研究接口地写「用户就是要 / 机制就是」。
- **为了好做改产物语义**：「做不出来所以改成尽力而为」被写进设计，而不回开。
- **排期和工具写进设计语义**：把两周排期、用哪个 CMS 写成设计选择。

### 用结构简约的刀砍错了对象

- **在效果对齐前谈更简单**：只有一个方案，或基线还没对齐，却在用剃刀。
- **把必要不变量剃成「概念太多」**：被剃项答得出它在为哪条已确认边界承重。
- **「好做 / 好看」当成结构简约**：对制作者省事是规划可达性，极简美学是风格偏好。
- **「干脆少做一点」写在设计收敛里**：那是战略取舍，应回开方向，不是结构简约。

### 拿来比较的草图被当成已生效的授权

- **候选当授权**：画出来是为了让后续比较看得见差异，却被规划或实现按它构造、占资源、对外生效。

## 模式具体说明

### 把这个域的行动权写成了另一档

这个域被写成某一档行动权，后文或交接却按更大的一档来用。最锋利的一刀是未覆盖被花成自由。同族还有延后被花成已决定、受约束开放被花成已指定、已指定被花成可改选、委托范围被花成无界，以及口头写着「开放」、手里却没有硬约束和验收。

可观察痕迹：同一域前后状态不一致；「未覆盖 / 延后」写过一次，后文出现「实现时按惯例补 / 先定下来别卡住」；看起来开放，却没有可选空间、硬约束或评价依据；整份设计没有状态账本，却宣布可以规划或实现。

它和通用目录的「开」超额极性相反：那里是被迫多想没批准的分支，这里是把授权缺席花成行动自由。它也可能被错收成「限定被丢掉后当默认」，那就把行动权错配收成了思维前缀丢失。

> 例｜知识工作流的检索策略
>
> 设计写：「检索策略本次未覆盖。」这句话买到的是：无权推断、应回流，或等预先授权的安全默认。它没有批准实现自己定一套检索。
>
> 下一节对实现说：「按常见 RAG 习惯补上即可。」未覆盖被花成自由。实现一旦补上，产物的可追溯性、召回边界和验收对象都可能被静默改写，而设计没有为这刀付过授权成本。
>
> 换一种接法：未覆盖就停在未覆盖，规划把它暴露为依赖；若必须给安全默认，写明默认值、适用条件和回流触发，不要写成「按惯例补」。
>
> 这个例子在讲什么：授权缺席不是行动自由。自由是设计明确授予的受约束开放、参数化或委托。

### 盖设计章，花方向、研究或规划的钱

在既定方向和已给现实边界里治理产物可能性，却拿去重选方向、宣布事实或机制，或把排期、工具、实例写进设计语义。

可观察痕迹：局部产物选择被写成「我们的方向就是……」；设计正文出现无研究接口的「用户就是要 / 机制就是」；「做不出来所以改成尽力而为」被写进设计而不回开；设计文档开始写两周排期和用哪个 CMS。

通用目录会收成「观察句被写成唯一行动」或「先走这边被写成没有别的路」。看见思维跳步，收错层：缺的不是又一次「值不值得」的通用压缩，而是这句根本不该由设计花。

> 例｜主产物被「细化存储」改掉
>
> 方向承诺是：「主产物给人读，可读性优先。」设计买到的是：在这个方向里，决定文档结构、可追溯性和未知如何显露。
>
> 设计借「细化存储」把主产物改成 JSON 库加检索接口，可读文档降成导出。接受这句会重选未来位置：主产物从给人读，变成给系统检索。这刀应回开方向承诺，不是由设计自行改写。
>
> 换一种接法：存储形态若会改变体验、可追溯性或验收对象，先写成待回开的方向问题；若这些保持不变，才可能只是规划或实现里的替代。
>
> 这个例子在讲什么：盖的是设计章，花的是方向的钱。换一种做法会不会改变体验、可追溯性、隐私或验收对象，是设计和规划的绝对岔路口。

### 用结构简约的刀砍错了对象

设计里的剃刀只许在效果已经对齐的候选之间，剃掉写不出承重挂钩的结构。说白了：先保证大家交出的效果一样好，再比谁的结构负担小。它被拿去砍方向、砍还没对齐的效果，或砍成「好做 / 好看」。

可观察痕迹：被剃项答得出它在为哪条已确认效果或边界承重；只有一个方案却在谈「更简单」；剃除理由是工期、工具顺手或视觉干净；「干脆少做一点」写在设计收敛里而不是回开方向。

通用目录会收成「够用被当成可以停找」或「自己的好坏标准被当成外部裁定」。看见停找或内生尺子，收错层：这里非法的是比较工具砍错了对象。

这条最可能不是独立家族，而是一条生成通路：砍方向时长成跨节点越权，把必要不变量剃成「不必有」时长成状态赋错。它留下来的理由是现场常有「我们比较过，选了更简单的」这句话。试筛若发现它总能归进另外两条，应降级。

> 例｜可追溯被当成「概念太多」
>
> 两个信息结构候选都要保住「来源可追溯、未知不可伪装成事实」。这句话是等效基线，不是可剃的负担。
>
> 评审把可追溯整段剃掉，理由是「概念太多，读者要新学」。被剃的那一段答得出它在为哪条已确认边界承重。这次「更简单」砍的不是结构负担，是基线本身。
>
> 换一种接法：先核对两个候选是否都覆盖目标效果和关键边界；只有都覆盖，才比谁的结构负担小。可追溯若被方向或已确认边界要求，它进基线，后续不作为可剃项。
>
> 这个例子在讲什么：砍掉了功能的方案不是「更简单」，是「没做到」，进不了比较池。对制作者省事属于规划，极简美学属于风格偏好，都不是结构简约。

### 拿来比较的草图被当成已生效的授权

画出来是为了让后续比较看得见差异，却被规划或实现按它构造、占资源、对外生效。

可观察痕迹：标题或口头仍是「若走这条 / 备选 / 草图」，任务或排期已按它开工；方向承诺缺失时，条件模型被实现直接消费；问「哪一版设计被交接条件放行」，答不上来。

通用目录会收成「方向句被当成已查完」。看见停止复检，收错层：这里不是一句工作缓存被当法庭宣判，是候选从未进入可消费端口，却被当成既有授权。

它和「未覆盖被花成自由」先不合并：前者是从未进入可消费端口，后者是已经在设计授权游戏里却赋错格。

> 例｜事件溯源草图进了迭代
>
> 架构讨论里有人画出：「若做事件溯源，节点会是这样。」这句话买到的是：让后续比较看得见一种可能。它没有买到产物语义已指定。
>
> 下周迭代直接按事件溯源写接口，当作已经生效的授权。标题仍是「若走这条」，任务已经按它开工。
>
> 换一种接法：草图保持候选；要让实现消费，必须先让该决策域落入已指定、受约束开放或委托，并写明载荷。问得出「哪一版被放行」，才能开工。
>
> 这个例子在讲什么：候选设计不是既有授权。画出来给人比较，不等于下游可以据此构造。

## 本目录不收什么

- 研究主张为假或过期：研究错误。
- 方向尚未承诺就被下游当已选：缺的是方向承诺。除非设计自己把局部选择写成方向，那才进「盖设计章」。
- 规划发现不可达，或为了好做而改产物语义：规划越权。设计若预先把语义改小来迁就工期，才进「盖设计章」。
- 实现把未覆盖项静默固定：实现越权。设计若事先把未覆盖写成「按惯例补」，才进状态赋错。
- 设计现场仍会大量长出通用模式：先看卡片流、后文把列表方案写成已否决；「这套信息结构能讲通」之后停找别的划法；暂用一个模块名，后文把对象锁死。对象仍是「接下来怎么想」，用[通用目录](./低质量判断的模式.md)收。
- 审美品味、「文档不够细」、单纯难做或不好看。后两样是规划可达性或风格偏好，除非被当成剃刀判据。

## 仍开放

- 「交接时没有状态账本却宣布设计完成」要不要从状态赋错里拆出来。现在收在契约尺度用法里。
- 空授权与状态赋错是否长期同族。
- 结构剃刀用错在真实设计稿里，是否总能归进另外两条。
- 现场把规划不可达、实现偷改叫成「设计错了」的误判有多常见。

这些要靠真实设计稿试筛，不在本文加家族。

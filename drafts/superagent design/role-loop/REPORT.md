# 职责协议与工程样题验证报告

本轮推进用户提出的战略引领者、军团长、监督者、执行 Agent 和独立验证职能的职责设计。候选协议见 `DESIGN.md`，本报告说明本轮实际取得的证据及其范围。

## 实际结果

运行了一次本地工程样题。战略由独立 Agent 定义阶段目标，主控担任军团长，两个执行 Agent 分别修复导出和重试实现，独立验证 Agent 建立并执行用户路径验收，监督 Agent 从外部检查任务状态与证据交接。

样题是主持人构造的带故障实现，包含按指定时区导出日报和确认丢失后重试两个问题。全部送达均在本地模拟，未接入真实外部服务。

| 检查 | 原始实现 | 修复后实现 |
| --- | ---: | ---: |
| 已有局部检查 | 3/3 通过 | 3/3 通过 |
| 独立用户路径用例 | 2/10 通过 | 10/10 通过 |
| 独立逐项条件 | 70/82 通过 | 82/82 通过 |
| 边界与时区用例 | 1/5 通过 | 5/5 通过 |
| 送达幂等用例 | 1/3 通过 | 3/3 通过 |
| 完整 CLI 用例 | 0/2 通过 | 2/2 通过 |

独立验证者实际调用命令行，核对输入、CSV、回执和送达数量。原始实现的 CLI 全部退出成功，但八个业务用例失败；已有局部检查没有覆盖这些错误。

修复前后使用同一冻结的计划、用例、运行器和预期结果。验证者与主控分别执行了两轮前后版本检查，正式对照均记录 Python 3.14.3。源文件在每次运行前后保持一致，修复后报告与候选清单一致，仅两份获分配的实现文件改变。版本与标准审计见 对应记录。

## 实际交接过程

- 战略首次依据主持人的目标摘要给出上海日期、UTC 兼容和确认丢失后的唯一送达要求。
- 主控运行已有局部检查，三项通过后保持“等待独立验收”，没有宣布整体完成。
- 独立监督读取原始任务说明、实现与运行记录，区分静态风险与实测结论，并指出验收还需覆盖指定时区的通用语义、字段内容和顺序。
- 战略读取完整原始说明后修订检查项。这里首次派发只有摘要，与完整说明存在信息差，属于主持人的信息交接缺口；不能据此认定战略 Agent 本身缺少相关能力。
- 独立验证者在运行被测实现前冻结十个用例，实际返回八个失败，结果直接进入军团长的处置记录。
- 军团长保持原标准，将时区和送达身份两处问题交给不同执行者，明确修改所有权与边界。
- 两个执行者分别实际修改文件、运行自检，并请求独立验证，没有自行宣告整体业务完成。
- 军团长核对仅指定的两份实现改变，形成候选版本；独立验证者使用原冻结验收取得 10/10 和 3/3 的结果。
- 主控重放原始及修复版本，核对输入、期望、验收哈希、候选哈希与实际结果的一致性，提交最后监督快照。
- 最终监督快照独立核对原三项发现已经闭合，未发现当前范围内的阻断或报告过度主张。军团长据原停止条件关闭本有限任务，交付、目标达成与停止原因记在 对应记录；整体研究目标仍保持进行中。

事件顺序保存在 运行时间线。初次角色派发参数转录在 派发记录；补充信息与回应见时间线、监督快照和本次运行记录。

## 对职责设计产生的修订

独立冷读在原候选协议中发现四处中严重度欠定义，修订后又发现一处自检与独立验证的权限歧义。全部已作文本修复并经定点复查，具体过程见 `design-cold-read.md`。

- 战略制定授权内的里程碑成功条件；军团长细化执行任务完成标准，不能削弱上层要求。
- 验证依据当前合法生效的标准及仍有效的用户约束。结论同时绑定标准版本、产物指纹和环境。
- 军团长接受约定容差内的残余问题。涉及上层成功条件或用户保留目标时，分别交战略或用户决定。
- 分别记录是否交付、目标是否达成和为何停止。有限任务由军团长按条件关闭，上层计划由战略按授权判断结束。
- 各被启用职责都要有失效信号、接替决定者与无替补时的处理安排，覆盖普通有限任务。
- 军团长可以调整执行团队自检和要求补验；独立验证者选择自己的检查方法与覆盖，不能被进度或局部通过替代。
- 战略、军团长、监督和验证都能回查原始目标与有效变更。摘要须带原文位置和版本。

这些修订提高了文本的可执行性。当前运行直接检验了其中的原目标回查、失败结果直达、修改责任分配、版本绑定和独立验收；其他修订仍有待对应运行场景验证。

## 能够支持的结论

本次分角色团队完成了这个有限工程样题，保留标准与失败证据，修复后获得同一验收的有效通过结果。原始局部通过不足以支撑完整交付的判断在本样题中获得了实际反例。

监督的原文回查和验证的独立选例发现了摘要及局部检查未覆盖的要求，军团长承接了修复与整体证据。这里直接支持的是信息与责任通路能够在一次实际执行中工作。

这不是随机化的架构对照实验。修复前后改变的是实现，不能把用例通过数的变化归因为角色数量，也不能据此证明完整分工优于使用同样验收的单 Agent。主持人知道植入故障，角色上下文分离但文件权限没有操作系统隔离，监督采用快照方式。当前未测长期运行、消息丢失、并发写入、进程崩溃接替、真实外发或经济收益。

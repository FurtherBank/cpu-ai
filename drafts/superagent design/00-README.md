# Superagent 结构探索资料

这份资料整理了此前围绕多 Agent 复杂任务协作结构的探索结果。内容集中在战略引领、任务指挥、独立监督、具体执行、独立验证、职责边界、版本交接、有限任务与持续服务的区别，以及真实工程样题验证。

## 资料范围

- `ARCHITECTURE-AND-BOUNDARY-ARGUMENT.md` 是结合收敛动力学与感知基准缺失案例完成的全量职责边界精准定义与真实任务失配纠错论证（`superagent` Skill 的直接上游规范）。
- `BOUNDARY-AUDIT.md` 是前一轮围绕四类职责与条件启用完成的单层边界初审记录。
- `role-research/DESIGN-v4.md` 是职责协议的候选版本。
- `role-research/REPORT.md` 是真实源码适配研究的总报告。
- `role-research/design-v4-cold-read.md` 保存独立冷读结果。
- `role-loop/DESIGN.md` 和 `role-loop/REPORT.md` 保存受控工程样题的设计与结果。
- `role-loop/design-cold-read.md` 保存样题设计的独立冷读结果。

## 证据边界

本资料包保留了探索结论、反例、实验结果和限制说明。源码、原始任务输入、运行器和过程元数据没有随包复制，因此其中关于源码和运行状态的事实应理解为当时研究报告中的证据摘要，不能仅凭本资料包重新执行或复核。

阅读顺序是职责协议、真实源码研究报告、工程样题设计与结果。

## 使用边界

这些材料用于继续研究职责结构和任务适用边界。它们不构成所有任务都应启用全部角色的结论，也不构成持续运行、跨领域泛化或整体效率已经得到证明的结论。
